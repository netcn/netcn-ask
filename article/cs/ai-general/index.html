01机器学习和传统写规则的程序有什么区别？监督学习怎么划分训练集和测试集？How does machine learning differ from hand-coded programs, and how does supervised learning split training and test sets?

ML 从样本归纳参数化规律，传统编程由人写规则；标注样本训练，独立测试集检验泛化。ML derives parameterized patterns from samples while traditional coding writes rules by hand; labeled data trains and an independent test set checks generalization.

机器学习是人工智能的一类方法：不再由人逐条编写规则，而是从标注样本中归纳出可用于新输入的规律。传统编程把规则和数据交给计算机算出答案；机器学习把数据和对应的答案交给算法，由模型调整内部参数得到规则，再用规则处理没见过的输入。分类、回归、识别和推荐都可以写成这种学习问题。Machine learning is one family of methods in artificial intelligence: instead of writing rules by hand one by one, the algorithm generalizes a usable pattern from labeled examples. Traditional programming hands the computer rules and data to produce answers; machine learning hands it data and corresponding answers, and the model tunes internal parameters to derive the rule, then applies that rule to unseen inputs. Classification, regression, recognition and recommendation can all be framed this way.[1][5]

监督学习是最常见的设定：训练集里每条样本都带标签，例如图片配类别、邮件配是否垃圾邮件。模型先在训练集上预测，与标签比较得到误差，反复调整参数降低误差；训练结束后用未参与训练的测试集评估，看规律是否迁移到新样本。训练误差低而测试误差高称为过拟合，说明模型记住了样本细节而没有抓住一般规律。Supervised learning is the commonest setting: every example in the training set carries a label, such as an image with a category or an email with a spam flag. The model predicts on training examples, compares against labels to measure error, and repeatedly adjusts parameters to lower it. After training, a test set not used in training checks whether the pattern transfers to new inputs. Low training error but high test error is overfitting: the model memorized sample details instead of capturing a general rule.[1][6]

样本、特征和划分是三个基本要素。特征是输入中被模型使用的可测量属性；数据要分成训练集、验证集和测试集，验证集用于调节超参数，测试集只在最终评估时使用。样本量过小会让结论不稳定，标签错误会把误差带入训练；特征选择决定模型能看到哪些信息。IBM 的机器学习资料把这一过程概括为从数据中识别模式并用于预测。Samples, features and splits are the three basic ingredients. A feature is a measurable property the model uses from the input; data are split into training, validation and test sets, with validation tuning hyperparameters and test reserved for final evaluation. Too few samples makes conclusions unstable, and label errors feed bias into training; feature selection decides what information the model sees. IBM's machine learning overview frames the process as identifying patterns in data for prediction.[1][6]

学习类型还包括无监督学习和强化学习。无监督学习处理没有标签的数据，寻找聚类或异常；强化学习通过试错与环境交互，用奖励信号调整策略。实际系统常组合多种设定，例如先用无监督方式表征数据，再用标注样本微调。判断一个任务是否适合机器学习，要看是否有足够代表性的数据、明确的目标指标，以及规则难以人工写清但规律可从样本估计的环节。Other learning settings include unsupervised learning and reinforcement learning. Unsupervised learning handles unlabeled data to find clusters or anomalies; reinforcement learning interacts by trial and error, adjusting policy against a reward signal. Real systems mix settings, for example unsupervised representation followed by labeled fine-tuning. A task suits machine learning when it has enough representative data, a clear target metric, and aspects hard to write by hand but estimable from samples.[1][6]

边界：机器学习得到的规律是统计关联，不等于因果解释；训练数据的偏差会被模型放大并在新场景复现。测试集表现只反映与训练数据同分布的情况，分布外输入可能给出不可靠结果。模型能力受样本覆盖和特征质量限制，不能把学习系统当作能自主理解世界的主体；具体精度取决于任务、数据和模型规模，不能用通用排名代替逐项评估。The boundary: learned patterns are statistical association, not causal explanation; biases in training data are amplified and reproduced in new settings. Test-set performance reflects inputs drawn from the same distribution, and out-of-distribution inputs can give unreliable results. Ability is bounded by sample coverage and feature quality, and a learning system should not be treated as an agent that understands the world on its own. Concrete accuracy depends on task, data and model scale, so general rankings cannot replace per-task evaluation.[1][5]

02神经网络是怎样计算预测的？反向传播和梯度下降在训练中具体做什么？How does a neural network compute predictions, and what do backpropagation and gradient descent do in training?

前向加权求和加激活函数得到预测；链式法则反向求梯度，梯度下降按学习率更新权重。Forward weighted sums and activations produce predictions; the chain rule back-computes gradients, and gradient descent updates weights at a learning rate.

神经网络由大量带权重的神经元分层连接而成：每个神经元对上一层输出做加权求和，再经过激活函数产生输出。网络从输入层到输出层逐层计算得到预测值，这一过程叫前向传播；训练时先把预测与真实标签比较，用损失函数给出误差大小，再沿网络反向把误差分摊到每个权重，这就是反向传播。A neural network connects many weighted neurons in layers: each neuron takes a weighted sum of the previous layer's output and passes it through an activation function. Computing from the input layer through the output layer to produce a prediction is the forward pass. Training first compares prediction with the true label, a loss function measures the error, then the error is allocated back to each weight through the network: this is backpropagation.[2][5]

反向传播的数学基础是链式法则。损失对最后一层权重的偏导由损失函数直接给出，再逐层向前乘上权重和激活函数的导数，得到损失对每一层参数的梯度；梯度下降按学习率 η 沿梯度反方向更新权重，w ← w − η∇L。Rumelhart、Hinton 和 Williams 1986 年在 Nature 发表的工作把这一方法推广到多层表示学习，成为现代深度网络训练的标准步骤。The mathematical basis of backpropagation is the chain rule. The loss derivative with respect to the last-layer weights comes straight from the loss function; moving layer by layer, derivatives multiply through weights and activation derivatives to give the gradient for every parameter. Gradient descent updates weights opposite the gradient at learning rate eta, w ← w − eta grad L. The 1986 Nature paper by Rumelhart, Hinton and Williams extended this to multilayer representation learning, and it became the standard step for modern deep network training.[2][4]

参数规模和训练目标要一起看。一个权重就是一个可调数字，现代网络参数量从数百万到数百亿不等；参数多并不等于理解，模型只是在拟合训练数据中的统计结构。损失函数决定优化方向：分类常用交叉熵，回归常用均方误差；学习率过大训练震荡，过小收敛缓慢。批量大小、层数和激活函数共同决定模型容量与训练成本。Parameter scale and training objective must be read together. A weight is one adjustable number; modern networks range from millions to hundreds of billions of parameters, but more parameters do not mean understanding: the model fits statistical structure in training data. The loss function sets the optimization direction: cross-entropy for classification, mean squared error for regression. A learning rate that is too large oscillates training, one too small converges slowly; batch size, depth and activation jointly set capacity and training cost.[2][5]

训练流程通常分几步：初始化权重，前向计算批量样本，统计损失，反向传播求梯度，更新参数，循环直到验证集性能不再提升。梯度在层间可能消失或爆炸，深层网络用归一化、残差连接等结构缓解。Nielsen 的在线教材用手写数字识别一步步演示了前向计算、损失下降和权重更新，便于对照理解。The training run has repeated steps: initialize weights, forward-compute a batch, measure loss, back-propagate gradients, update parameters, and loop until validation performance stops improving. Gradients can vanish or explode across layers, and deep networks use normalization and residual connections to relieve this. Nielsen's online textbook walks through handwritten digit recognition step by step, showing forward computation, loss decline and weight update side by side.[2][5]

边界：反向传播是优化数学，不保证收敛到全局最优，网络可能停在局部较优点；训练好的权重编码的是统计映射，不是人类可读的规则。参数量大的模型在分布外任务上同样可能失效，训练数据不足时大模型更容易记住噪声。神经网络适合有数据、有可微分目标的学习问题，不能解释成机器拥有意图或理解；具体识别精度要在独立测试集上测量。The boundary: backpropagation is optimization mathematics; it does not guarantee a global optimum, and the network may settle at a local better point. Trained weights encode a statistical mapping, not human-readable rules. Large-parameter models still fail out of distribution, and with insufficient data large networks more easily memorize noise. Neural networks suit learning problems with data and a differentiable objective; they should not be read as machines with intent or understanding. Recognition accuracy must be measured on an independent test set.[2][4]

03注意力机制怎么让模型关注相关位置？自注意力的计算量为什么随序列长度平方增长？How does attention focus a model on relevant positions, and why does self-attention compute quadratically with sequence length?

查询-键相似度加权求和值向量；n 个位置形成 n×n 矩阵，每层约 O(n²·d)。Query-key similarity weights a value sum; n positions form an n×n matrix at about O(n²·d) per layer.

注意力机制让模型在处理一个词或样本时，动态决定关注哪些其他位置。自注意力为每个输入位置生成查询、键、值三组向量，查询与所有键做点积相似度，经 softmax 归一化成权重，再按权重加权求和值向量。Transformer 用多层自注意力堆叠，不依赖循环顺序，能一次看到序列内全部位置。Attention lets a model decide dynamically which other positions to focus on when processing a token or sample. Self-attention generates query, key and value vectors for each input position; query-key dot products give similarity, softmax turns it into weights, and values are weighted-summed. A Transformer stacks multiple self-attention layers without recurrent order, seeing every position in the sequence at once.[2][3]

复杂度随序列长度平方增长。n 个位置两两计算注意力，相似度矩阵是 n×n，每层注意力的计算量约为 O(n²·d)，d 为每维通道数；长度翻倍，注意力计算量约变四倍。这是长上下文成本上升的主要原因。Vaswani 等人 2017 年论文《Attention Is All You Need》提出 Transformer 架构，用多头注意力并行提取不同关系，取代了早期循环网络的顺序处理。Complexity grows with the square of sequence length. n positions are compared pairwise, the similarity matrix is n by n, and per-layer attention runs about O(n²·d), where d is the channel dimension; doubling length roughly quadruples attention compute. This drives the rising cost of long context. The 2017 paper Attention Is All You Need by Vaswani and colleagues proposed the Transformer, using multi-head attention in parallel to extract different relations, replacing the sequential processing of early recurrent networks.[2][3]

多头注意力把表示分到多个子空间，每头关注一类关系，例如语法搭配或指代；拼接后再经线性变换。位置编码把顺序信息注入模型，因为自注意力本身不自带先后顺序。大语言模型在此基础上堆叠多层注意力与前馈网络，参数量从数亿到数千亿，参数保存的是连接权重和统计模式，而不是逐条背诵的句子库。Multi-head attention splits representations into subspaces, each head tracking one relation type such as grammatical pairing or coreference; heads are concatenated and passed through a linear transform. Positional encoding injects order information, because self-attention carries no inherent sequence order. Large language models stack many attention and feed-forward layers on this base, from hundreds of millions to hundreds of billions of parameters; parameters hold connection weights and statistical patterns, not a memorized sentence database.[2][3]

这些机制对应可观测的工程现象。上下文长度受注意力计算和显存限制，超长输入需要滑动窗口、稀疏注意力等近似；训练成本随层数、宽度和序列长度上升。注意力权重可视化可以看到模型对哪些词分配了较高权重，但权重分布不等于因果解释。不同任务选择模型规模时，要在数据质量、推理成本和目标指标之间权衡。These mechanisms match observable engineering behavior. Context length is bounded by attention compute and memory, and very long inputs rely on sliding windows, sparse attention and similar approximations. Training cost rises with depth, width and sequence length. Visualized attention weights show which tokens receive higher weight, but the weight distribution is not a causal explanation. Model size for a task trades data quality, inference cost and target metrics.[2][6]

边界：自注意力的平方复杂度不意味着所有模型都按此比例增长，具体实现有稀疏化和缓存优化；注意力权重是相关性分配，不直接说明模型“理解”了内容。大模型在知识截止后的事件、推理严谨性和分布外输入上仍可能出错，参数规模不保证结论正确。Transformer 是当前主流架构之一，但不是唯一可行的神经网络结构；具体效果仍需在任务基准上独立评测。The boundary: self-attention's quadratic complexity does not mean every implementation grows by that ratio, since sparsification and caching apply. Attention weights are a relevance allocation, not proof that the model understands content. Large models can still err on events after their knowledge cutoff, on rigorous reasoning and out-of-distribution inputs; parameter scale does not guarantee correct conclusions. The Transformer is one dominant architecture, not the only viable neural design, and concrete results still need independent benchmark evaluation.[2][3]
