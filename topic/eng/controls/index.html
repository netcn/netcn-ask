经典控制里的“根轨迹”和“奈奎斯特判据”分别用什么方式判断系统稳不稳定？

In classical control, how do the root locus and Nyquist criterion each judge whether a system is stable?

根轨迹看闭环极点随增益在复数平面上的移动，一旦越过虚轴就失稳；奈奎斯特则看开环频率响应曲线是否包围临界点来判断闭环稳定。一个在时域、一个在频域，殊途同归。
Root locus tracks how closed-loop poles move in the complex plane with gain—crossing the imaginary axis means instability. Nyquist checks whether the open-loop frequency curve encircles a critical point. One is time-domain, the other frequency-domain, but both agree.

李雅普诺夫稳定性理论和“看特征值”有什么不同，为什么非线性系统离不开它？

How does Lyapunov stability theory differ from 'looking at eigenvalues', and why is it essential for nonlinear systems?

线性系统可凭特征值符号判定稳定，但非线性系统没有固定特征值。李雅普诺夫直接构造一个“能量函数”，只要它随时间下降就证明系统会回到平衡，不必求解方程。
Linear systems can be judged by eigenvalue signs, but nonlinear ones have no fixed eigenvalues. Lyapunov directly builds an 'energy function'; if it keeps decreasing, the system returns to equilibrium—without solving the equations.

什么是状态空间模型和“观测器”，当某些状态无法直接测量时怎么估计？

What is a state-space model and an observer, and how do you estimate states you cannot measure directly?

状态空间用一组变量完整描述系统演化，观测器则利用可测输出和模型，反推出那些装不了传感器的内部状态。就像通过体温和心率推测身体内部状况一样。
State space describes a system by a set of variables; an observer uses measurable outputs and the model to infer internal states lacking sensors. It is like guessing internal condition from temperature and heart rate.
