大规模MIMO基站部署几十上百根天线，究竟换来什么好处？

What benefit do massive-MIMO base stations gain from deploying dozens or even hundreds of antennas?

当天线数远大于同时服务的用户数时，各用户的信道向量趋于相互正交并出现“信道硬化”，简单的线性预编码就能把每路信号在空间上对准各自用户、彼此几乎不干扰，多个用户因而可以共用同一时频资源，频谱效率成倍提升；全部天线的相干叠加还带来阵列增益，用更低的发射功率即可维持原速率。Marzetta的论文最早给出了这一极限性能分析。
When antenna count greatly exceeds the number of simultaneously served users, user channel vectors become nearly mutually orthogonal and exhibit “channel hardening”: simple linear precoding can focus each signal spatially onto its intended user with little mutual interference, so many users share the same time-frequency resource and spectral efficiency multiplies. Coherent combining across all antennas additionally provides array gain, maintaining throughput at lower transmit power. Marzetta's seminal paper first quantified these asymptotic gains.

5G大规模MIMO基站不转动任何天线，靠什么原理把无线波束对准用户？

By what principle does a 5G massive-MIMO base station point its radio beams at users without moving any antenna?

这是相控阵原理：基站给阵列中每副天线馈入带独立相位与幅度权值的同一信号，各单元波前仅在目标方向同相叠加、其他方向相消，等效波束即被“电扫”向该用户。权值来自信道估计：TDD制式上下行共用同一频带、信道互易，基站测得上行导频的信道响应即可直接算出下行权值，无需反馈开销，也无需任何机械转动。
This is the phased-array principle: the station feeds every antenna element the same signal with its own phase and amplitude weights, so the elementary wavefronts add coherently only toward the target user and cancel elsewhere, steering the synthesized beam electronically. The weights come from channel estimation: in TDD the uplink and downlink share one band, the channel is reciprocal, and uplink pilots directly yield the downlink weights—no feedback overhead and no moving parts.

用户开车经过小区边界时，蜂窝网络靠什么机制保证通话和数据业务不中断？

What mechanism lets a cellular network keep calls and data sessions running while a user crosses a cell boundary in a moving vehicle?

核心是切换：终端持续对服务小区和邻区进行信号强度与质量测量并上报。当满足触发条件（如3GPP定义的A3事件——邻区信号优于服务小区一个偏置量并持续一段时间），网络便命令终端改挂到新小区的无线资源上继续通信。协议还配置滞后偏置与触发时延，防止终端在边界处来回“乒乓”切换，以此在移动中维持会话连续。
The key process is handover. The handset continuously measures signal strength and quality from its serving cell and neighbours and reports the results; when a trigger such as 3GPP Event A3 fires — a neighbour staying better than the serving cell by an offset for a set time — the network moves the phone onto the new cell's radio resources. Hysteresis margins and time-to-trigger delays stop ping-ponging at the boundary, preserving session continuity.
