RISC-V 为什么被称为“开源指令集”？

Why is RISC-V called an 'open-source instruction set'?

RISC-V 的指令集规范以开放许可发布，任何公司或个人都能免费使用、实现甚至扩展它，而不必像 x86、ARM 那样向持有者付费授权，因此吸引了大量学术与产业定制。
RISC-V's instruction-set spec is released under open licenses, so anyone can use, implement or extend it free of charge—unlike x86 or ARM which require paid licenses—spurring lots of custom silicon.

RISC-V 的向量扩展（RVV）是怎么设计的？

How is RISC-V's vector extension (RVV) designed?

RVV 采用“可变向量长度”（VLEN）和按元素编程的方式：同一段代码能跑在不同宽度的硬件上，硬件有多少位宽就一次处理多少数据，方便从微控制器扩展到大型加速器。
RVV uses a variable vector length (VLEN) and element-wise programming: the same code runs on hardware of any width, processing as many elements as the unit has bits, scaling from microcontrollers to big accelerators.

什么是指令集，为什么 RISC-V 这么受关注？

What is an instruction set, and why is RISC-V getting attention?

指令集是 CPU 能听懂的“基本命令表”，软件最终都翻译成这些命令。RISC-V 因为免费开放、可自由裁剪，让学校和公司都能自己设计芯片，所以很受关注。
An instruction set is the basic command list a CPU understands; all software ultimately becomes these commands. RISC-V is free and open and can be trimmed to taste, so schools and firms can design their own chips.
