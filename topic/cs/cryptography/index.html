迪菲-赫尔曼（Diffie-Hellman）密钥交换解决了什么问题？

What problem does Diffie-Hellman key exchange solve?

迪菲与赫尔曼在 1976 年提出一种方法，让双方在公开的、可能被窃听的信道上各自选取私有随机数，却仍能协商出同一个共享密钥，而窃听者无法算出它。它依赖离散对数问题的困难性，是现代密钥协商（如 TLS 中的 DHE/ECDHE）的鼻祖，NIST 在 SP 800-56A 中规范了其使用。它只负责协商密钥、本身不提供身份认证，须配合证书或签名机制以防中间人攻击。
Diffie and Hellman (1976) proposed a method by which two parties, over a public and possibly eavesdropped channel, each choose a private random value yet agree on the same shared secret that an eavesdropper cannot compute. It rests on the hardness of the discrete logarithm problem and is the ancestor of modern key agreement such as DHE/ECDHE in TLS, with its use standardized in NIST SP 800-56A. It only establishes a key and provides no authentication by itself, so it must be paired with certificates or signatures to prevent man-in-the-middle attacks.

什么是前向安全性？

What is forward secrecy?

前向安全性指即便长期私钥日后泄露，过去通信的会话密钥依然安全，因为每次会话都用临时密钥协商并随即丢弃。它依赖 Diffie-Hellman 类密钥交换，是现代 TLS 的推荐特性。
Forward secrecy means that even if a long-term private key leaks later, past session keys stay safe, because each session negotiates ephemeral keys that are discarded. Relying on Diffie–Hellman key exchange, it is a recommended feature of modern TLS.

密码学中的哈希函数有何特点？

What are the properties of a cryptographic hash function?

密码学哈希函数把任意消息压缩成定长摘要，要求单向（难以反推原文）、抗碰撞（难找两个不同输入同摘要）且微小改动必产生大变化。SHA-256 广泛用于数字签名与区块链。
A cryptographic hash function compresses any message to a fixed-length digest, requiring one-wayness (hard to invert), collision resistance (hard to find two inputs with the same digest), and strong avalanche (tiny changes flip the output). SHA-256 is widely used in signatures and blockchains.

RSA 公钥密码体制的基本思想是什么？

What is the basic idea behind the RSA public-key cryptosystem?

RSA 由里维斯特、沙米尔与阿德曼在 1978 年提出，使用一对密钥：公开的公钥用于加密、私有的私钥用于解密。其安全性建立在『大整数分解』的困难性上——两个大素数相乘容易，但反过来分解乘积极难。它同时支撑加密与数字签名，是 HTTPS 等现代安全通信的支柱之一，NIST 将其列为标准公钥算法。
Proposed by Rivest, Shamir, and Adleman in 1978, RSA uses a key pair: a public key for encryption and a private key for decryption. Its security rests on the difficulty of factoring large integers—multiplying two large primes is easy, but factoring the product is extremely hard. It underpins both encryption and digital signatures and is a standard public-key algorithm recognized by NIST, supporting secure communication such as HTTPS.

AES（高级加密标准）是什么？它用什么方式工作？

What is AES (Advanced Encryption Standard), and how does it work at a high level?

AES 是美国国家标准与技术研究院（NIST）于 2001 年通过 FIPS 197 确立的对称分组加密标准，取代老旧的 DES。它把 128 位数据块按轮次进行字节替换、行移位、列混合和轮密钥加等可逆变换，密钥长度可为 128/192/256 位。由于其效率高且经严密审查，AES 被广泛用于磁盘加密、Wi-Fi（WPA2/3）和 VPN 等场景。
AES is the symmetric block-cipher standard adopted by NIST in 2001 via FIPS 197, replacing the aging DES. It processes 128-bit blocks through repeated rounds of byte substitution, row shifting, column mixing, and round-key addition, with key sizes of 128, 192, or 256 bits. Efficient and heavily vetted, AES is widely used for disk encryption, Wi-Fi (WPA2/3), VPNs, and more.

什么是公钥密码学？

What is public-key cryptography?

公钥密码学使用一对密钥：公开的公钥用来加密或验证，保密的私钥用来解密或签名。它解决了在不安全信道上安全分发密钥的难题，RSA 与椭圆曲线是典型算法。
Public-key cryptography uses a key pair: a public key for encryption or verification and a private key for decryption or signing. It solves secure key distribution over insecure channels; RSA and elliptic curves are typical algorithms.

什么是数字签名？

What is a digital signature?

数字签名用发送者的私钥对消息摘要加密，接收者用其公钥验证，既能确认来源真实、又证明内容未被篡改且不可抵赖。它是电子合同与软件分发信任的基础。
A digital signature encrypts a message digest with the sender's private key; the receiver verifies with the public key, confirming authenticity, integrity, and non-repudiation. It underpins trust in e-contracts and software distribution.
