什么是操作系统中的信号（Signal）？

What are signals in an operating system?

信号是进程间的一种异步通知，比如按 Ctrl+C 会发送 SIGINT 让程序终止。程序可捕获或忽略某些信号。
A signal is an asynchronous notification between processes; pressing Ctrl+C sends SIGINT to terminate a program. Programs can catch or ignore some signals.

什么是优先级调度和轮转（Round Robin）？

What are priority scheduling and round-robin?

优先级调度让重要任务先跑；轮转则给每个任务固定时间片轮流执行，保证公平。两者常结合使用。
Priority scheduling runs important tasks first; round-robin gives each task a fixed time slice in turn for fairness. They are often combined.

什么是死锁？怎么避免？

What is a deadlock, and how can it be avoided?

死锁是多个进程互相等待对方持有的资源，谁都无法前进。常见避免方法：按固定顺序加锁、设置超时、一次性申请全部资源。
A deadlock is when processes each wait for a resource the other holds, so none proceeds. Avoid it by locking in a fixed order, using timeouts, or requesting all resources at once.

什么是实时操作系统（RTOS）？

What is a real-time operating system (RTOS)?

RTOS 保证任务在确定的时间内完成，常用于汽车刹车、医疗设备等对延迟有严格要求的场景，而非追求平均最快。
An RTOS guarantees tasks finish within bounded time, used in cars' brakes or medical devices where latency is critical, not just average speed.

什么是文件系统？FAT、NTFS、ext4 是什么？

What is a file system, and what are FAT, NTFS, and ext4?

文件系统是硬盘上组织文件的规则。FAT 简单老旧，NTFS 是 Windows 常用，ext4 常见于 Linux，它们管文件名、权限和存放位置。
A file system is the rules for organizing files on disk. FAT is old and simple, NTFS is common on Windows, and ext4 is typical on Linux; they manage names, permissions, and locations.

什么是中断（Interrupt）？

What is an interrupt?

中断是硬件或软件发出的有急事信号，CPU 暂停当前工作去处理（如键盘按键、网卡来数据），处理完再回来。
An interrupt is an urgent signal from hardware or software; the CPU pauses current work to handle it, such as a key press or network packet, then resumes.

什么是上下文切换（Context Switch）？

What is a context switch?

当 CPU 从一个任务换到另一个，需要保存当前寄存器、内存映射等状态再恢复下一个，这过程叫上下文切换，频繁切换会有开销。
To switch tasks, the CPU saves the current registers and memory map, then restores the next task's; that overhead is a context switch, and frequent switches cost time.

什么是进程和线程？它们有什么区别？

What are processes and threads, and how do they differ?

进程是运行中的程序，拥有独立内存空间；线程是进程里的执行流，同一进程内的线程共享内存，切换更轻量。
A process is a running program with its own memory; a thread is an execution flow inside a process. Threads in one process share memory and switch more cheaply.

什么是内存泄漏？

What is a memory leak?

程序借了内存却忘了还，就像借了小朋友的玩具一直不还，时间久了玩具越来越少，电脑也会变慢甚至卡住。
A program borrows memory but forgets to give it back, like borrowing a friend's toy and never returning it; soon there are fewer toys and the computer slows down or freezes.
