什么是 B 树，为什么数据库用它？

What is a B-tree and why do databases use it?

B 树是一种平衡的多路搜索树，每个节点可含多个键和子节点，从而让树保持矮胖。它把多个键放在一个磁盘页里，大幅减少访问磁盘的次数，因此被关系型数据库的索引广泛采用（如 B+ 树）。
A B-tree is a balanced multi-way search tree where each node holds many keys and children, keeping the tree short and wide. Packing several keys per disk page greatly reduces disk accesses, so B-trees (especially B+ trees) are widely used for indexes in relational databases.

红黑树和 AVL 树都是自平衡二叉搜索树，它们的主要区别是什么？

Both red-black trees and AVL trees are self-balancing binary search trees; what is their main difference?

AVL 树要求任意节点左右子树高度差不超过 1，平衡更严格，查找更快但插入删除时旋转开销更大；红黑树只保证从根到叶子的每条路径黑色节点数相同（近似平衡），旋转次数更少，写入更轻量。因此红黑树常用于需要频繁修改的场景（如 C++ std::map、Java TreeMap），AVL 树更适合查找密集的场景。二者都保证操作在 O(log n) 时间内完成。
An AVL tree requires the height difference of any node's subtrees to be at most 1, giving stricter balance and faster lookups but more rotations on insert/delete; a red-black tree only guarantees equal numbers of black nodes on every root-to-leaf path (approximate balance), so it performs fewer rotations and lighter writes. Red-black trees suit frequent modifications (e.g., C++ std::map, Java TreeMap), while AVL trees fit lookup-heavy use. Both guarantee O(log n) operations.

B 树和 B+ 树常用于什么场景？

What are B-trees and B+ trees commonly used for?

B 树和 B+ 树是面向磁盘等外部存储的多路平衡搜索树，一个节点可容纳多个键，从而降低树的高度、减少磁盘访问次数。B+ 树把所有真实数据放在叶子节点并用链表串起来，非常适合范围查询。它们是关系型数据库索引的核心结构。
B-trees and B+ trees are multi-way balanced search trees designed for external storage like disks, with each node holding many keys to reduce tree height and disk accesses. A B+ tree keeps all actual data in leaf nodes linked in a list, which is ideal for range queries. They are the core structures of relational database indexes.

什么是红黑树？

What is a red-black tree?

红黑树是一种自平衡的二叉搜索树，每个节点带颜色（红或黑）并满足一组平衡规则，确保最长路径不超过最短路径的两倍。插入和删除在最坏情况下也能保持 O(log n) 的时间复杂度。它是许多语言标准库（如 C++ map、Java TreeMap）的底层结构。
A red-black tree is a self-balancing binary search tree in which each node is colored red or black and follows a set of balance rules, guaranteeing the longest path is at most twice the shortest. Insertion and deletion remain O(log n) in the worst case. It underlies many standard libraries such as C++ map and Java TreeMap.

什么是堆和优先队列？

What are heaps and priority queues?

堆是一种特殊的完全二叉树，能保证根节点始终是最大（大顶堆）或最小（小顶堆）元素。优先队列是抽象概念，常用堆实现，使得每次取出的都是优先级最高/最低的元素。它广泛用于任务调度和图算法中的最短路径。
A heap is a special complete binary tree that guarantees the root is always the maximum (max-heap) or minimum (min-heap) element. A priority queue is an abstraction usually implemented with a heap, so the highest- or lowest-priority element is retrieved each time. It is widely used in task scheduling and shortest-path graph algorithms.

什么是链表？

What is a linked list?

链表由一系列节点组成，每个节点保存数据和指向下一个节点的指针，因此元素在内存中不必连续存放。插入和删除只需改动指针、效率很高，但随机访问需要从头遍历，速度较慢。
A linked list consists of nodes, each holding data and a pointer to the next node, so elements need not be stored contiguously in memory. Insertion and deletion are efficient—just rewire pointers—but random access requires traversal from the head, which is slow.

哈希表如何处理冲突？常见的两种策略是什么？

How do hash tables handle collisions, and what are two common strategies?

哈希冲突指不同键被映射到同一槽位，常用两种策略解决：链地址法把同一槽位的元素用链表串起来；开放寻址法在冲突时按探测序列在表内寻找下一个空槽。链地址法实现简单且对负载因子更宽容，开放寻址法缓存局部性更好。负载因子过高时二者性能都会下降，通常需要扩容再哈希。
A hash collision occurs when distinct keys map to the same slot, and two common strategies resolve it: separate chaining stores collided elements in a linked list per slot, while open addressing probes for the next empty slot within the table. Chaining is simple and tolerates higher load factors, whereas open addressing has better cache locality. Both degrade as the load factor rises and usually require resizing and rehashing.

什么是堆？

What is a heap?

堆是一种特殊的完全二叉树，最大堆中每个父节点都不小于其子节点，最小堆则相反。借助堆可以在 O(log n) 内插入或删除最值，并能在 O(n) 内建堆，是堆排序和优先队列的基础。
A heap is a special complete binary tree where in a max-heap every parent is at least as large as its children (the reverse for a min-heap). It supports inserting or removing the extreme value in O(log n) and can be built in O(n), underpinning heapsort and priority queues.

什么是二叉树？

What is a binary tree?

二叉树是一种每个节点最多有两个子节点（通常称为左子节点和右子节点）的树形结构。它是表达层次关系、实现高效查找（如二叉搜索树）的基础。许多高级结构，如堆和红黑树，都是二叉树的变体。
A binary tree is a tree structure in which each node has at most two children, usually called the left and right child. It is the basis for expressing hierarchies and enabling efficient search, such as in binary search trees. Many advanced structures like heaps and red-black trees are variants of binary trees.

什么是缓存（cache）和局部性原理？

What is a cache and the principle of locality?

缓存是介于高速 CPU 和慢速主存之间的小容量高速存储器，用来存放近期可能被再次使用的数据。局部性原理指程序倾向于重复访问附近或最近的数据，因此缓存能大幅提升性能。缓存命中时速度快，未命中则需从更慢的存储取数据。
A cache is a small, fast memory placed between the fast CPU and slow main memory to hold data likely to be reused soon. The principle of locality observes that programs tend to access nearby or recently used data, so caches greatly improve performance. A cache hit is fast; a miss requires fetching from slower storage.

什么是栈和队列？

What are stacks and queues?

栈是一种「后进先出」（LIFO）的结构，最后放进去的元素最先取出，像一摞盘子。队列是「先进先出」（FIFO）的结构，最先进入的元素最先离开，像排队买票。它们是计算机中最基础的线性数据结构。
A stack is a last-in-first-out (LIFO) structure where the most recently added element is removed first, like a pile of plates. A queue is first-in-first-out (FIFO) where the earliest element leaves first, like a ticket line. They are among the most fundamental linear data structures.

计算机用什么「数」来数东西？

How do computers count things?

我们平时用 0 到 9 十个数字，叫十进制；计算机只用 0 和 1 两个数字，叫二进制。开关的「开」表示 1、「关」表示 0，所有信息都由无数个 0 和 1 组合而成。这就是计算机能处理一切的基础。
We normally use ten digits from 0 to 9, called decimal; computers use only two digits, 0 and 1, called binary. A switch on means 1 and off means 0, and all information is made of countless 0s and 1s. This is the foundation that lets computers process everything.

哈希表是怎么工作的？

How does a hash table work?

哈希表通过哈希函数把键映射成一个数组下标，从而能在平均 O(1) 时间内完成查找、插入和删除。当两个不同的键被映射到同一个位置时，就会发生「哈希冲突」，常用链地址法或开放寻址法解决。它是字典和集合等类型的底层实现。
A hash table uses a hash function to map a key to an array index, enabling average O(1) lookup, insertion, and deletion. When two different keys map to the same location, a hash collision occurs, commonly resolved by chaining or open addressing. It underlies dictionary and set types.

栈（stack）和队列（queue）有什么区别？

What is the difference between a stack and a queue?

栈是后进先出（LIFO）结构，只能在一端压入和弹出，像一摞盘子；队列是先进先出（FIFO）结构，从一端入队、另一端出队，像排队买票。两者的插入删除顺序截然相反，分别对应函数调用回溯和任务缓冲等典型场景。它们是几乎所有程序都依赖的基础线性结构。
A stack is last-in-first-out (LIFO): you push and pop only from one end, like a pile of plates. A queue is first-in-first-out (FIFO): items enter at one end and leave at the other, like a ticket line. Their insertion and removal orders are opposite, serving function-call unwinding and task buffering respectively, and both are fundamental linear structures used by nearly every program.

数组和链表有什么不同？

What is the difference between an array and a linked list?

数组在内存中是连续存放的，可以通过下标在 O(1) 时间随机访问任意元素，但插入删除可能需要移动大量数据。链表由一个个节点通过指针连接，插入删除方便，但只能顺序遍历访问。两者各有适用场景。
An array stores elements contiguously in memory, allowing O(1) random access by index but possibly requiring large data moves for insertion or deletion. A linked list connects nodes via pointers, making insertion and deletion easy but access only sequential. Each has its own suitable use cases.

什么是图这种数据结构？

What is a graph data structure?

图由一组顶点（节点）和连接它们的边组成，用来表示对象之间的任意关系。社交网络中的好友关系、地图上的道路都是图的例子。根据边是否有方向，图可分为有向图和无向图。
A graph consists of a set of vertices (nodes) and edges connecting them, used to represent arbitrary relationships between objects. Examples include friendships in a social network and roads on a map. Depending on whether edges have direction, graphs are divided into directed and undirected.
