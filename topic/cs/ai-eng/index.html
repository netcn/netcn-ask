什么是 dropout 和正则化？它们怎样抑制过拟合？

What are dropout and regularization, and how do they curb overfitting?

正则化对过大的参数施加惩罚，逼模型更简洁；dropout 训练时随机关掉部分神经元，防止大家过度依赖彼此，提升泛化。
Regularization penalizes large weights for simplicity; dropout randomly turns off neurons during training to stop over-reliance, improving generalization.

什么是混淆矩阵、精确率和召回率？

What are a confusion matrix, precision, and recall?

混淆矩阵列出预测对错的各种情况。精确率是预测为正的里真正正的比例，召回率是真正为正的里被找出来的比例，两者常需权衡。
A confusion matrix shows prediction outcomes. Precision is of those predicted positive how many truly are; recall is of all true positives how many we found, often a trade-off.

反向传播是怎么让神经网络学习的？

How does backpropagation train a neural network?

前向传播算出预测与真实标签之间的损失；反向传播从输出层往回，用链式法则逐层计算损失对每个权重的偏导，也就是每个参数该往哪个方向调、调多少；再按梯度下降用学习率更新权重，让损失变小。如此反复迭代直到收敛。关键洞察是：链式法则让梯度能高效地在整张计算图上传递。
Forward propagation computes a loss between prediction and true label; backpropagation then walks backward from the output, using the chain rule to compute the loss gradient with respect to every weight—which direction and how far each parameter should move—and gradient descent updates the weights by the learning rate to shrink the loss. Repeating this converges. The key insight: the chain rule lets gradients flow efficiently across the whole computation graph.

RLHF（基于人类反馈的强化学习）是怎么让大模型更"听话"的？

How does RLHF (reinforcement learning from human feedback) make LLMs more helpful and aligned?

RLHF 分三步：先用指令数据做有监督微调；再让人类对多个候选回答排序，训练奖励模型拟合这些偏好；最后用 PPO 等强化学习算法以奖励模型为反馈更新策略模型，并通过 KL 惩罚约束它不要偏离参考模型太远。ChatGPT 等模型借此对齐人类偏好、减少有害和偏离指令的输出。
RLHF has three steps: supervised fine-tuning on instruction data; training a reward model on human preference rankings of candidate answers; then optimizing the policy with a reinforcement-learning algorithm like PPO using that reward, with a KL penalty keeping it close to the reference model. Models like ChatGPT use it to align with human preferences and reduce harmful or off-instruction outputs.

Transformer 为什么用"多头"注意力而不是单头注意力？每个头学到什么？

Why does Transformer use multi-head attention instead of a single head? What does each head learn?

单头注意力只有一个注意力分布，难以同时建模句法、指代、语义等不同类型的关系。多头把 Query、Key、Value 投影到 h 个不同的低维子空间并行计算注意力，再把输出拼接后投影回来。不同头会分化出不同职责——有的关注相邻词，有的捕捉指代和句法依赖，既增强了表达能力，又天然可并行。
A single attention head has one attention distribution, which struggles to model syntax, coreference and semantics simultaneously. Multi-head projects Query, Key, Value into h separate low-dimensional subspaces, computes attention in parallel, then concatenates and re-projects the outputs. Heads specialize — some track adjacent words, others capture coreference or syntactic dependencies — boosting expressiveness while remaining naturally parallel.

大语言模型是怎么“学会”生成文本的？

How do large language models learn to generate text?

大模型在互联网规模文本上训练，任务是“预测下一个词”。Transformer 的注意力机制让模型根据上下文给不同位置的词加权，捕捉长距离依赖；经过大量预训练，模型内部表示隐式编码了语法、事实和推理模式。生成时逐词自回归采样，所以它在“计算下一个词的概率”，而不是检索现成句子。
LLMs train on internet-scale text by predicting the next token. The Transformer's attention mechanism weights words by relevance to the context, capturing long-range dependencies; after massive pretraining, internal representations implicitly encode grammar, facts, and reasoning patterns. Generation is autoregressive, sampling word by word—it computes probabilities for the next token rather than retrieving stored sentences.

大模型推理里的 KV 缓存是什么，为什么长对话会吃掉大量显存？

What is the KV cache in LLM inference, and why do long conversations eat so much GPU memory?

自回归生成每一步都要让新 token 对之前所有位置做注意力，若每步重算全部键（K）与值（V），计算量随序列长度平方增长；KV 缓存把每层每个已生成位置的 K、V 存下来复用，把单步计算降到线性。代价是显存占用大约等于 2 × 层数 × 头数 × 头维度 × 序列长度 × 批大小 × 每个数值的字节数，随上下文长度线性增长，长上下文时常超过权重本身。工程上用多查询或分组查询注意力减少 KV 头数、用 PagedAttention 分页管理碎片、以及对缓存做量化来压缩。
Autoregressive decoding makes each new token attend to every earlier position, and recomputing all keys and values at every step would cost work quadratic in sequence length; the KV cache stores per-layer K and V for already-generated positions so each step becomes linear. The price is memory of roughly 2 × layers × heads × head_dim × sequence_length × batch × bytes_per_value, which grows linearly with context and for long contexts often exceeds the model weights. Serving systems shrink it with multi-query or grouped-query attention (fewer KV heads), paged allocation as in PagedAttention, and quantizing the cache itself.

什么是模型剪枝（Pruning）？和量化有什么不同？

What is model pruning, and how does it differ from quantization?

剪枝是直接删除模型中不重要的连接或神经元，让网络变稀疏；量化是降低数值精度。两者都为了更小更快，可结合使用。
Pruning removes unimportant connections or neurons to make the network sparse; quantization lowers numeric precision. Both shrink and speed up models and can combine.

什么是过拟合？怎么判断和处理？

What is overfitting, and how is it detected and handled?

过拟合是模型把训练数据里的噪声也背下来了，训练误差很低，换新数据却表现差——本质是模型复杂度过高，容量超过了真实规律。判断方法：训练集与验证集/测试集准确率差距拉大。应对手段：收集更多数据、正则化（L1/L2 惩罚大权重）、Dropout 随机丢弃神经元、早停和交叉验证选超参。
Overfitting means the model memorizes noise in the training data: training error is tiny but performance on new data collapses—essentially the model's complexity exceeds the true underlying pattern. It shows up when accuracy on training data far exceeds validation/test accuracy. Remedies: more data, regularization (L1/L2 penalties on large weights), dropout randomly disabling neurons, early stopping, and cross-validation for hyperparameters.

模型量化是怎么让大模型"瘦身"的？从 FP16 到 INT8 为什么会损失精度？

How does quantization slim down large models, and why does going from FP16 to INT8 cost accuracy?

量化把权重和激活从浮点（FP16/FP32）映射到低精度整数（INT8 甚至 4bit），显著减少内存、带宽与计算量，推理速度大增。精度损失源于舍入误差和数值范围压缩：INT8 只有 256 个取值档位，细小数值被抹平。业界用校准数据选择缩放因子、逐通道量化、混合精度等手段弥补，GPTQ 等后训练量化能在精度几乎无损的情况下压缩模型。
Quantization maps weights and activations from floating point (FP16/FP32) to low-precision integers (INT8 or even 4-bit), drastically cutting memory, bandwidth and compute while boosting inference speed. The accuracy loss comes from rounding error and range compression: INT8 has only 256 levels, flattening fine numerical detail. Calibration-based scale selection, per-channel quantization and mixed precision help, and post-training methods like GPTQ compress models with almost no accuracy loss.

什么是大模型的规模定律，Chinchilla 纠正了此前的什么误区？

What are neural scaling laws, and what did Chinchilla correct about earlier practice?

规模定律指模型的交叉熵损失随参数量、训练 token 数和算力按平滑的幂律下降，因此性能在相当宽的范围内可以外推预测。Kaplan 等 2020 年的结果倾向于在固定算力下优先把参数堆大；Hoffmann 等 2022 年的 Chinchilla 工作重做了扫描实验，发现算力最优配置下参数量与训练 token 数应大致等比例增长，约每个参数配 20 个 token，说明此前的巨型模型普遍训练不足。按此配方训练的 700 亿参数 Chinchilla 在多项基准上胜过 2800 亿参数的 Gopher，直接改变了业界的取舍方向。
Scaling laws describe how a language model's cross-entropy loss falls as a smooth power law in parameters, training tokens and compute, which makes performance predictable by extrapolation across orders of magnitude. Kaplan et al. (2020) implied that a fixed compute budget should be spent mostly on parameters; Hoffmann et al.'s 2022 Chinchilla study redid the sweep and found the compute-optimal recipe grows parameters and tokens roughly in proportion, about 20 tokens per parameter, meaning earlier giant models were badly undertrained. A 70-billion-parameter Chinchilla trained that way outperformed the 280-billion Gopher on many benchmarks and shifted the field toward smaller models fed far more data.

大模型为什么常常数不清一个单词里有几个字母？

Why do large language models often miscount the letters inside a word?

模型看不到字符，它读到的是分词器切出的 token；BPE 之类的子词算法可能把 strawberry 切成 str、aw、berry 这样两三块，每块只是一个整数编号。字母层面的结构在嵌入向量里被压缩掉了，模型只能从训练文本中间接学到常见词的拼写，遇到罕见词或要求逐字计数就容易出错。让它先把单词一个字母一个字母地拆开写出来，或者把计数交给代码工具执行，都能显著提高正确率。
The model never sees characters; it sees tokens produced by a tokenizer, and subword schemes such as BPE may split strawberry into two or three chunks like str, aw and berry, each merely an integer id. Letter-level structure is compressed away in the embedding, so the model can only infer spelling indirectly from training text and stumbles on rare words or explicit counting requests. Asking it to spell the word out one letter at a time, or delegating the count to a code tool, raises accuracy sharply.

调用大模型时的 temperature 和 top-p 参数各自在改什么？

What do the temperature and top-p settings actually change when calling a language model?

模型每步输出词表上的一个概率分布，temperature 先把 logits 除以 T 再做 softmax：T 小于 1 让分布更尖锐、输出更保守也更容易重复，T 大于 1 让分布更平坦、更发散也更易出错，T 趋于 0 等价于每步取最大概率的贪心解码。top-p 也叫核采样，换一个思路：把候选按概率从高到低累加，只保留累计概率达到 p 的最小集合，归一化后再采样，从而动态截掉长尾里数量庞大但概率极低的词。两者常配合使用，事实性任务倾向低温度加较小的 p，创意写作则相反。
At each step the model emits a probability distribution over the vocabulary; temperature divides the logits by T before the softmax, so T below 1 sharpens it into safer but more repetitive text, T above 1 flattens it into more diverse but error-prone text, and T approaching 0 becomes greedy decoding. Top-p, or nucleus sampling, takes a different route: it sorts candidates by probability, keeps the smallest set whose cumulative mass reaches p, renormalizes and samples from that, dynamically cutting off the enormous low-probability tail. The two are usually combined — low temperature with a modest p for factual work, the opposite for creative writing.

Transformer 的注意力机制是做什么的？"注意力"体现在哪里？

注意力让模型在编码或生成每个词时，动态地为序列中其他位置分配不同的权重，重点参考与当前词相关的信息。缩放点积注意力用 Query 与 Key 的相似度作为权重，经 softmax 归一化后对 Value 加权求和，从而把"该关注什么"变成可学习的参数。
Attention lets the model, when encoding or generating each token, dynamically assign different weights to other positions in the sequence, focusing on the parts relevant to the current token. Scaled dot-product attention scores the similarity between Query and Key, normalizes it with softmax, and takes the weighted sum of Values, making "what to attend to" a learnable parameter.

This hierarchical feature learning broke through in 2012 and now powers lane and pedestrian detection in self-driving cars.

为什么大语言模型会一本正经地说错话？"幻觉"是怎么产生的？

Why do LLMs confidently say wrong things? Where does hallucination come from?

大模型的核心是预测下一个词，它追求"流畅合理"而非"与事实一致"，在知识盲区会编造看似可信的内容，这就是幻觉。成因包括训练数据中的噪声、模型知识边界模糊、解码时偏向高频表达等；检索增强生成（RAG）、要求给出处和事实核查能有效缓解。
LLMs are fundamentally next-token predictors that optimize for fluency rather than factual accuracy, so they fabricate plausible-sounding content at the edge of their knowledge — that is hallucination. Causes include noisy training data, fuzzy knowledge boundaries and decoding bias toward common patterns; retrieval-augmented generation (RAG), citation requirements and fact-checking mitigate it.

监督学习和无监督学习有什么不同？

What is the difference between supervised and unsupervised learning?

监督学习用“带标签”的数据训练——每个样本都有正确答案，模型学习输入到输出的映射，用于分类（垃圾邮件识别）和回归（房价预测）。无监督学习只有数据没有标签，模型自己发现结构，典型任务是聚类（用户分群）和降维。差别就在“有没有老师告诉它正确答案”。
Supervised learning trains on labeled data—every sample has the correct answer—so the model learns input-to-output mappings for classification (spam detection) and regression (housing price prediction). Unsupervised learning has only data, and the model finds structure itself, typically clustering (segmenting users) and dimensionality reduction. The difference is whether a “teacher” provides correct answers.

机器学习里为什么要把数据分成训练、验证、测试三份？

Why split data into training, validation, and test sets in machine learning?

训练集用来调权重，验证集用来选超参数和监控过拟合，测试集只在最后评估一次，模拟“从没见过的新数据”。如果拿测试集反复调参，模型会悄悄适应它，评估分数虚高，发布后实际效果缩水。严格分离才能给出可信的性能估计。
The training set fits weights, the validation set tunes hyperparameters and monitors overfitting, and the test set is evaluated exactly once at the end, simulating unseen data. Reusing the test set to tune parameters lets the model quietly adapt to it, inflating scores that then drop in production. Strict separation is the only way to get an honest performance estimate.

训练数据和测试数据为什么要分开？

Why split training and testing data?

用同一批数据训练和打分，模型可能只是背答案。分开测试才能公平检验它在没见过的数据上是否真会做题。
Scoring on the same data used to train lets the model just memorize answers. A separate test fairly checks performance on unseen data.
