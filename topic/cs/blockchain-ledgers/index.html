工作量证明(PoW)如何达成去中心化共识，又为何害怕 51% 攻击?

How does proof of work achieve decentralized consensus, and why is a 51% attack feared?

PoW 要求节点投入算力求解一个难算易验的哈希难题，最长链被公认为有效账本，使诚实算力占优时篡改成本极高。若某个实体掌握过半算力，就能以概率优势构造更长私有链来双花或阻止交易确认，从而破坏共识安全。
PoW forces nodes to spend computation solving a hard-but-verifiable hash puzzle, and the longest chain is accepted as the valid ledger, making tampering extremely costly while honest hash power dominates. If an entity controls over half the power, it can probabilistically build a longer private chain to double-spend or block confirmations, breaking consensus security.

默克尔树(Merkle Tree)如何让轻节点高效验证一笔交易是否存在?

How does a Merkle tree let a lightweight node efficiently verify that a transaction is included?

区块把所有交易两两哈希自底向上聚合成一棵二叉树，根哈希写入区块头。轻节点只需保存根哈希，配合从目标交易到根的一小段哈希路径（Merkle 证明），即可在对数级数据量下验证该交易确属该区块，而不必下载全部交易。
A block hashes transactions pairwise upward into a binary tree whose root hash goes into the block header. A lightweight node keeps only the root and, given the short hash path from the target transaction to the root (a Merkle proof), can verify inclusion in logarithmic-sized data without downloading all transactions.

区块链为什么被称为「链」，其基本数据结构是怎样的?

Why is a blockchain called a chain, and what is its basic data structure?

区块链由按时间顺序排列的区块组成，每个区块除自身数据外还包含前一个区块的哈希值，从而像指针一样把区块前后串接成链。任何对历史区块的篡改都会改变其哈希，并导致后续所有区块的链接失效。
A blockchain is an ordered sequence of blocks, each containing not only its own data but also the hash of the previous block, chaining them together like pointers. Any tampering with a historical block changes its hash and breaks the links of every subsequent block.

区块链「不可篡改」的特性主要来自哪些机制?

Which mechanisms mainly give a blockchain its immutability property?

不可篡改来自区块间的哈希链接、分布式多副本存储以及共识机制的经济成本：改一处历史需重算其后所有区块的工作量并说服多数节点接受。由于全网共同维护同一账本，单一节点难以悄悄伪造记录。
Immutability comes from hash chaining between blocks, distributed replication across many nodes, and the economic cost of consensus: rewriting history means redoing the proof-of-work of all later blocks and convincing the majority. Because the whole network maintains one ledger, a single node cannot silently forge records.

密码学哈希函数在区块链中主要发挥哪些作用?

What main roles do cryptographic hash functions play in a blockchain?

哈希函数把任意长度输入映射为固定长度摘要，且难以逆向或找到碰撞，因此被用来链接区块、标识交易以及在工作量证明中构造难度目标。它的确定性使全网节点能对同一数据得到一致的摘要。
A hash function maps arbitrary input to a fixed-length digest that is hard to invert or collide, so it links blocks, identifies transactions, and builds the difficulty target in proof of work. Its determinism lets all nodes derive the same digest for the same data.

区块链上的「智能合约」指的是什么?

What does a smart contract on a blockchain refer to?

智能合约是部署在区块链上的可执行程序，其代码与状态由全网节点共同维护，并在满足预设条件时自动执行。由于运行在去中心化环境中，它能在没有中介的情况下实现可信的自动交易与约定。
A smart contract is an executable program deployed on a blockchain whose code and state are maintained by all nodes and that runs automatically when preset conditions are met. Running in a decentralized environment, it enables trustworthy automatic transactions and agreements without an intermediary.

加密货币中公钥和私钥分别用来做什么?

What are public and private keys used for in cryptocurrencies?

私钥由持有者秘密保存，用于对交易进行数字签名以证明所有权；公钥由私钥推导而来并公开，他人用它验证签名并生成收款地址。谁掌握私钥谁就控制对应资产，因此私钥的保密至关重要。
The private key is kept secret and used to digitally sign transactions to prove ownership, while the public key is derived from it and shared so others can verify signatures and derive a receiving address. Whoever holds the private key controls the associated funds, so keeping it secret is essential.
