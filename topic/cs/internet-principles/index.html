什么是负载均衡？

What is load balancing?

负载均衡把大量请求分散到多台服务器上，避免单台过载并提高整体可用性和响应速度。它可按轮询、最少连接或哈希等策略分配流量。配合健康检查还能在服务器故障时自动剔除。
Load balancing spreads many requests across multiple servers to avoid overloading one and to improve availability and speed. It can distribute by round-robin, least connections, or hashing. With health checks it can drop failing servers automatically.

什么是 NAT，它解决了什么问题？

What is NAT and what problem does it solve?

NAT（网络地址转换）让多台内网设备共用一个公网 IP 上网，通过在路由器上改写包的源地址实现。它缓解了 IPv4 地址不足，也隐藏了内网结构。代价是增加了连接复杂性，并对某些点对点应用不友好。
NAT (network address translation) lets many internal devices share one public IP by rewriting packet source addresses at the router. It eases IPv4 shortage and hides internal structure. The cost is extra connection complexity and poor fit for some peer-to-peer apps.

PageRank 是怎样利用网页之间的链接来给重要性打分的？

How does PageRank use links between web pages to score importance?

PageRank 把链接视为『投票』：被很多重要页面指向的页面更重要，并迭代求解一个稳定的权重分布，相当于在随机游走中停留在某页的概率。Page 与 Brin 等在 1998–1999 年提出，成为 Google 早期排序核心。
PageRank treats links as votes: a page pointed to by many important pages is itself important, solved as a stable weight distribution—the probability of landing on a page during a random walk. Page and Brin et al. proposed it in 1998–1999, becoming Google's early ranking core.

什么是子网掩码？

What is a subnet mask?

子网掩码是一串与 IP 等长的二进制数，用来划分地址中“网络部分”和“主机部分”。把 IP 与掩码做按位与，就能得到网络号，从而判断两台机器是否在同一子网。它是划分子网、控制广播范围的基础。
A subnet mask is a binary string as long as the IP that separates the network portion from the host portion. Bitwise-AND of IP and mask yields the network number, telling whether two machines share a subnet. It underlies subnetting and broadcast control.

TLS 握手过程大致是怎样的？

What does a TLS handshake roughly look like?

TLS 握手先由客户端发送支持的加密套件，服务器选定后发送证书以证明身份。双方再协商出对称密钥，之后通信内容都用该密钥加密。现代握手还支持会话复用以减少往返延迟。
In a TLS handshake the client sends supported cipher suites; the server picks one and sends a certificate to prove identity. Both then derive a symmetric key used to encrypt the session. Modern handshakes also support session resumption to cut latency.

什么是 CDN，它如何加速访问？

What is a CDN and how does it speed up access?

CDN（内容分发网络）把网站内容缓存到离用户更近的多个节点，用户从就近服务器获取，减少距离带来的延迟。它还能分摊源站压力、提升可用性和抗攻击能力。视频和大图网站尤其依赖它。
A CDN (content delivery network) caches site content on many nodes closer to users, so they fetch from a nearby server and cut distance latency. It also offloads the origin and improves availability and resilience. Video and image-heavy sites depend on it.

什么是 IPv6，为什么需要它？

What is IPv6 and why is it needed?

IPv6 是新一代 IP 协议，地址长达 128 位，可提供几乎无限的地址空间。IPv4 地址已耗尽，难以支撑物联网等海量设备。IPv6 还简化了报头并内置更好的安全性。
IPv6 is the new generation IP with 128-bit addresses, offering a nearly unlimited space. IPv4 addresses are exhausted and cannot support the huge number of IoT devices. IPv6 also simplifies headers and builds in better security.

数据包在网络中是如何被路由的？

How are data packets routed through a network?

路由器根据目标 IP 地址查询路由表，选择下一跳把数据包转发出去，逐跳逼近目的地。每跳可能走不同路径，因此包可能乱序到达，由 TCP 负责重组。路由协议让路由器交换拓扑信息以选最优路。
Routers consult a routing table by destination IP and forward each packet to the next hop, getting closer hop by hop. Packets may take different paths and arrive out of order, with TCP reassembling them. Routing protocols let routers exchange topology to pick good paths.

协同过滤是怎么『从相似用户的行为』猜出你可能喜欢什么的？

How does collaborative filtering guess what you might like from similar users' behavior?

协同过滤基于『口味相近的人会做相近选择』：找到与你历史评分相似的用户群（基于用户）或相似物品群（基于物品），用他们的偏好预测你的空缺评分。Resnick 等在 1994 年用于群组推荐，Koren 等在 2009 年用矩阵分解大幅提升精度。
Collaborative filtering assumes similar people choose similarly: it finds users or items close to yours and predicts your missing ratings from theirs. Resnick et al. used it for group recommendations in 1994; Koren et al. boosted accuracy with matrix factorization in 2009.

HTTP 和 HTTPS 的主要区别是什么？

What is the main difference between HTTP and HTTPS?

HTTP 传输的内容是明文，容易被窃听和篡改；HTTPS 在 HTTP 外层加了 TLS 加密与身份认证。现在主流网站默认使用 HTTPS 以保护用户数据。浏览器也会标记纯 HTTP 站点为不安全。
HTTP sends content in plaintext, easy to eavesdrop or alter; HTTPS wraps HTTP with TLS encryption and authentication. Most sites now default to HTTPS to protect users. Browsers also flag plain HTTP sites as insecure.

路由器和交换机有什么不同？

How do routers and switches differ?

交换机工作在局域网内部，根据 MAC 地址把数据转发到同一网络的具体设备。路由器连接不同网络，根据 IP 地址在网与网之间选路。简单说，交换机管“同一栋楼”，路由器管“楼与楼之间”。
A switch works inside a local network, forwarding by MAC address to specific devices. A router connects different networks and routes by IP address between them. Simply put, the switch manages one building, the router manages between buildings.

为什么建立连接需要“三次握手”？

Why does connection setup need a three-way handshake?

TCP 三次握手让通信双方确认彼此的发送和接收能力都正常，并协商初始序列号。第一次请求、第二次确认、第三次再确认，避免旧连接请求造成混乱。它保证了可靠连接的起点一致。
The TCP three-way handshake lets both sides confirm their send and receive abilities and agree on initial sequence numbers. Request, acknowledge, then acknowledge again prevents confusion from stale connection requests. It ensures a consistent, reliable starting point.

什么是网络端口？

What is a network port?

端口是 0 到 65535 的数字编号，用来在同一台机器上区分不同的服务或应用。IP 地址找到主机，端口找到主机里的具体程序，如 80 用于网页、443 用于 HTTPS。它让一台服务器可同时运行多种服务。
A port is a number from 0 to 65535 that distinguishes services on one machine. The IP finds the host and the port finds the specific program, e.g. 80 for web and 443 for HTTPS. It lets one server run many services at once.

什么是 DNS，它有什么用？

What is DNS and what does it do?

DNS（域名系统）像互联网的电话簿，把便于记忆的域名如 example.com 翻译成机器用的 IP 地址。没有它，你得记住一长串数字才能访问网站。查询通常由你的运营商或公共 DNS 服务器完成。
DNS (Domain Name System) is the internet's phone book, translating memorable names like example.com into the IP addresses machines use. Without it you would memorize long number strings to visit sites. Your provider or a public DNS server usually handles the lookup.

什么是 URL？

What is a URL?

URL（统一资源定位符）是网页或资源在互联网上的地址，通常包含协议、域名和路径。例如 https://example.com/page 中，https 是协议，example.com 是主机，/page 是路径。它告诉浏览器去哪里、用什么方式获取内容。
A URL (Uniform Resource Locator) is the address of a web page or resource, usually with a protocol, domain, and path. In https://example.com/page, https is the protocol, example.com the host, and /page the path. It tells the browser where and how to fetch content.
