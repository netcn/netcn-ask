什么是双拼输入法？

What is the Shuangpin (double-pinyin) input method?

双拼把每个拼音的声母和韵母都映射到单独一键，打一个字只需两键，击键更少、速度更高，但需要短期记忆键位。
Shuangpin maps each initial and final to one key, so a syllable takes just two presses—fewer keystrokes, higher speed, but needs learning the layout.

五笔输入法为什么能让打字更快？

Why can the Wubi input method type faster?

五笔按汉字字形拆成字根分布在25个键上，重码很少，熟练后可盲打，速度常高于拼音输入，由王永民在1983年发明。
Wubi splits characters into radicals on 25 keys, has few duplicates, and allows blind touch-typing, often faster than pinyin; it was invented by Wang Yongmin in 1983.

为什么说“中文输入”曾经是个大难题？

Why was 'Chinese input' once a hard problem?

汉字常用字几千、字形复杂且没有现成的字母序列，早期既无键盘对应也无高效检索，直到智能输入法和编码方案成熟才解决。
Thousands of complex characters with no natural letter sequence made early input hard; it was solved only with coding schemes and smart input methods.

注音符号是干什么用的？

What are Zhuyin symbols used for?

注音符号（ㄅㄆㄇㄈ）是台湾地区用来标注汉字读音的符号系统，注音输入法据此把读音变成文字。
Zhuyin (ㄅㄆㄇㄈ) is a phonetic system used in Taiwan to mark pronunciation; a Zhuyin input method turns it into characters.

语音输入为什么越来越准？

Why is voice input getting more accurate?

端到端的深度学习把声音直接映射到文字，配合海量数据训练，对方言、口音和噪声环境的适应能力越来越强。
End-to-end deep learning maps audio straight to text and, trained on huge data, handles dialects, accents, and noisy environments far better.

计算机内部是如何给汉字编码的？

How are Chinese characters encoded inside computers?

汉字先用编码标准映射成数字，如GB2312（1980年，收6763字）、GBK、GB18030；国际上用Unicode把各国文字统一编号。
Characters are mapped to numbers by standards like GB2312 (1980, 6763 chars), GBK, and GB18030; internationally Unicode unifies scripts under one numbering.

表情符号（emoji）是汉字吗，它们怎么存储？

Are emoji Chinese characters, and how are they stored?

emoji不是汉字，但它们和汉字一样属于Unicode字符，UTF-8编码下常占用多个字节，所以能跨平台显示。
Emoji are not Chinese characters, but like them they are Unicode code points, often taking several UTF-8 bytes, so they display across platforms.

为什么有些汉字在某些设备上显示成方框“□”？

Why do some Chinese characters show as empty boxes '□' on some devices?

那是因为设备或字体缺少该字的字形轮廓，生僻字或新造字尤其容易“缺字”，装上对应字库即可正常显示。
It means the font lacks a glyph for that character; rare or new characters especially go missing, and installing the right font fixes it.

拼音输入法是怎么把拼音变成汉字的？

How does a pinyin input method turn pinyin into Chinese characters?

你打拼音后，输入法在候选字库里找出同音字，再用语言模型根据上下文挑出最可能的词，还能联想和纠错。
After you type pinyin, the method lists homophones and uses a language model to pick the most likely word from context, with prediction and correction.

为什么有时打开中文文件会显示成“乱码”？

Why do Chinese files sometimes show as gibberish?

当文件保存的编码（如UTF-8）和打开程序以为的编码（如GBK）不一致时，字节被错误翻译成奇怪字符，统一用UTF-8可避免。
When a file’s encoding (e.g. UTF-8) differs from what the opener assumes (e.g. GBK), bytes are misread as odd characters; using UTF-8 consistently avoids this.

Unicode是把全世界文字放进一张大表吗？

Does Unicode put all the world’s scripts into one big table?

Unicode给每个字符一个唯一码点，例如“中”是U+4E2D，全球文字统一编号，UTF-8是它的一种变长存储方式。
Unicode assigns each character a unique code point, e.g. 中 is U+4E2D, unifying scripts worldwide; UTF-8 is one variable-length way to store it.
