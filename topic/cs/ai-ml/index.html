什么是"幻觉"，大语言模型为什么会产生它？

What is a 'hallucination' and why do LLMs produce them?

幻觉指模型生成看似合理但事实错误的内容。因为它按概率预测下一个词而非检索真实事实，缺乏事实校验时就会编造。
A hallucination is plausible but false content. Because LLMs predict the next word by probability rather than retrieving facts, they can fabricate when not grounded in evidence.

什么是过拟合，如何避免？

What is overfitting and how can it be avoided?

过拟合指模型把训练数据的噪声也记住了，导致在新数据上表现差。可用更多数据、正则化、提前停止和交叉验证来缓解。
Overfitting is when a model memorizes training noise and performs poorly on new data. It is reduced with more data, regularization, early stopping, and cross-validation.

什么是训练数据和测试数据？

What are training data and test data?

模型先用训练数据学习规律，再用没见过的测试数据检验它是否真的学会，防止只是死记硬背。
A model learns from training data, then is checked on unseen test data to see if it truly generalized rather than just memorized.

什么是强化学习？

What is reinforcement learning?

强化学习让智能体在环境中试错，通过奖励和惩罚来学习能最大化长期回报的策略，AlphaGo 就是典型例子。
Reinforcement learning trains an agent by trial and error using rewards and penalties to learn a policy that maximizes long-term reward; AlphaGo is a famous example.

监督学习和无监督学习有什么区别？

What is the difference between supervised and unsupervised learning?

监督学习使用带正确答案标签的数据来训练；无监督学习面对没有标签的数据，自行发现其中的结构和分组。
Supervised learning trains on data with correct labels; unsupervised learning finds structure and groups in data that has no labels.

什么是神经网络？

What is a neural network?

神经网络由许多层相连的处理单元（神经元）组成，通过调整连接权重从数据中学习复杂关系，是深度学习的基础。
A neural network is layers of connected units (neurons) that learn complex relationships by adjusting connection weights, forming the basis of deep learning.

什么是训练一个AI模型？

What does it mean to train an AI model?

训练就是让模型反复调整内部参数，使它对训练数据的预测越来越准，就像学生不断练习改错题。
Training repeatedly adjusts a model's internal parameters so its predictions on the data improve, like a student practicing and fixing mistakes.

什么是机器学习？

What is machine learning?

机器学习让计算机从大量数据中发现规律，而不是由人把每条规则都写死，学会后就能对新数据做预测。
Machine learning lets computers find patterns from lots of data instead of being given every rule, then make predictions on new data.

电脑是怎么"学"东西的？

How does a computer 'learn' things?

电脑看到很多例子后，会慢慢找出其中的规律，下次遇到新的就能猜对，这就像小朋友多看几次就学会认猫。
After seeing many examples, a computer finds the pattern and can guess right on new ones—like a child learning to recognize cats after a few tries.
