安全多方计算（MPC）的威胁模型假设了什么？

What does the threat model of secure multi-party computation (MPC) assume?

MPC 假设参与方互不信任，但其中最多有 t 个（可设）会作恶或串谋；它保证即使这些恶意方合谋，也学不到其他方的私输入，只能得到约定的计算结果。它不抵抗所有方一起作弊。
MPC assumes mutually distrusting parties where at most t (a chosen threshold) may cheat or collude; it guarantees they learn nothing beyond the agreed result even if they collude, but cannot stop everyone cheating together.

同态加密允许在密文上做哪些计算？

What computations does homomorphic encryption allow on ciphertext?

同态加密让你可以直接对加密数据做加法、乘法等运算，得到的结果解密后等于对明文做同样运算的结果。这样云服务器能在看不到原始数据的情况下完成计算，典型应用如加密的投票统计或隐私查询。
Homomorphic encryption lets you add or multiply encrypted data so that decrypting the result equals doing the same op on plaintext. A server can compute without seeing the data—e.g. tallying encrypted votes or private queries.

联邦学习怎么做到不把本地数据传出去也能训练模型？

How does federated learning train without sending local data out?

各设备先用本地数据训练模型，只把更新后的参数或梯度（而非原始数据）加密上传，服务器聚合成一个更好的全局模型再下发。原始数据始终留在设备上，从而保护隐私。
Each device trains locally and uploads only model updates or gradients—not raw data—which the server aggregates into a better global model and sends back. Raw data never leaves the device.

差分隐私是如何用数学方式保护个人数据的？

How does differential privacy mathematically protect individuals?

差分隐私在统计结果里加入经过标定的随机噪声，使得任何单条记录“在或不在”数据集中都不会显著改变输出。这样即使攻击者拿到结果，也难以反推出某个具体人的信息，并用参数 ε 控制泄露程度。
Differential privacy adds carefully calibrated random noise so that any single record's presence barely changes the output. An attacker seeing the result can't pin down one person, with a parameter ε bounding the leakage.
