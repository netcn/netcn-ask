像 BBR 这样的拥塞控制算法目标是什么？

What is the goal of congestion-control algorithms like BBR?

传统算法靠丢包来“感觉”网络拥堵，往往要么太保守要么把缓冲区填满。BBR 通过测量带宽和往返时延来建模真实瓶颈，尽量以最高吞吐、最低时延发送，而不是等丢包才减速。
Classic algorithms infer congestion from packet loss, often under- or over-shooting. BBR models the real bottleneck by measuring bandwidth and RTT, sending at maximum throughput with minimal delay instead of waiting for loss.

BGP 为什么被形容为“互联网的邮政路由”？

Why is BGP described as the internet's postal routing?

BGP 是各自治系统（AS）之间交换“去哪条路可达”的边界网关协议，靠策略而非最短距离选路，就像邮政按行政区划逐段转发。它缺乏内置的安全校验，因此曾出现路由被蓄意“劫持”的事件。
BGP is the protocol by which autonomous systems exchange 'which path reaches where', choosing by policy rather than pure distance—like postal mail handed zone by zone. It lacks built-in security, so routes have been hijacked.

子网掩码是做什么用的？

What is a subnet mask used for?

子网掩码用比特位把 IP 地址分成网络号和主机号两部分，路由器据此判断目标地址是否在同一子网，从而决定是直接投递还是转发到网关。
A subnet mask splits an IP into network and host portions; routers use it to decide whether a destination is on the local subnet or must be forwarded to a gateway.

QUIC 协议相比传统的 TCP+TLS 解决了哪些痛点？

What pain points does QUIC solve versus classic TCP+TLS?

QUIC 基于 UDP，把传输与加密握手合并，实现 0-RTT 或 1-RTT 建连，远快于 TCP 三次握手再加 TLS。它还把多个数据流放在同一连接且相互隔离，单个流丢包不会阻塞其他流，缓解了队头阻塞。
QUIC runs over UDP and merges transport with encrypted handshake, enabling 0/1-RTT setup versus TCP's three-way plus TLS. It multiplexes independent streams in one connection, so one lost stream doesn't block others, easing head-of-line blocking.

DNS 是不是就像互联网的“电话簿”？

Is DNS like the internet's phone book?

是的。我们记的是“example.com”这样的名字，电脑要的是 IP 地址。DNS 负责把名字翻译成数字地址，就像电话簿把人名查成电话号码，你才连得上网站。
Yes. We remember names like 'example.com' but computers need IP addresses. DNS translates names to numeric addresses, like a phone book turning a name into a number so you can reach the site.

为什么有时候网页打不开？

Why do web pages sometimes fail to load?

可能是网络断连、服务器太忙、域名解析失败或浏览器缓存出错；刷新、检查 Wi-Fi 或换个时间再试通常能解决。
It could be a dropped connection, a busy server, failed name resolution or a bad cache; refreshing, checking Wi-Fi or trying later usually helps.
