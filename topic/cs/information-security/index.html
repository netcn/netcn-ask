密码学中的哈希函数有什么用？

What is the use of hash functions in cryptography?

密码学哈希函数能把任意长度输入变成固定长度的「摘要」，且难以反推原文、难以找到碰撞。它用于验证数据完整性、存储密码（加盐哈希）和构造数字签名。例如 SHA-256 是比特币等系统广泛使用的哈希算法。
A cryptographic hash function turns input of any length into a fixed-length digest that is hard to invert and hard to collide. It verifies data integrity, stores passwords (with salting), and builds digital signatures. For example, SHA-256 is widely used in Bitcoin and other systems.

什么是 SQL 注入攻击？

What is an SQL injection attack?

SQL 注入是攻击者把恶意 SQL 代码拼接到输入中，欺骗数据库执行非预期命令的攻击方式。它常因程序直接拼接用户输入而引起，可能泄露或破坏整个数据库。使用参数化查询（预编译）可有效防范。
SQL injection is an attack where malicious SQL is concatenated into input to trick the database into executing unintended commands. It often arises when programs directly concatenate user input and can leak or destroy an entire database. Parameterized (prepared) queries effectively prevent it.

什么是社会工程学攻击？

What is a social engineering attack?

社会工程学攻击不靠技术漏洞，而是利用人的信任或疏忽来骗取密码、验证码等敏感信息，例如伪装成客服的钓鱼电话。它是很多数据泄露的入口。提高安全意识和核实身份是主要防范手段。
A social engineering attack exploits human trust or carelessness rather than technical flaws to obtain passwords, codes, and other sensitive information, such as a phishing call pretending to be support. It is the entry point of many breaches. Awareness and identity verification are the main defenses.

为什么密码不能太简单？

Why shouldn't passwords be too simple?

简单的密码（如 123456）很容易被自动程序试出来，就像用小钥匙开大门。使用长且包含字母、数字、符号的组合能大幅提高破解难度。再加上双因素认证就更安全了。
Simple passwords like 123456 are easily guessed by automated programs, like using a tiny key on a big door. Long combinations of letters, digits, and symbols greatly raise the difficulty of cracking. Adding two-factor authentication makes it even safer.

什么是数据加密？

What is data encryption?

加密是把可读的明文通过密钥转换成难以理解的密文，只有掌握正确密钥的人才能还原。它保护信息在传输和存储时不被窃听或篡改。现代加密是网络支付和隐私保护的基础。
Encryption transforms readable plaintext into incomprehensible ciphertext using a key, and only someone with the correct key can reverse it. It protects information from eavesdropping or tampering during transmission and storage. Modern encryption underpins online payments and privacy protection.

什么是计算机病毒？

What is a computer virus?

计算机病毒是一种能自我复制并附着到其他程序上的恶意代码，会在用户不知情时传播和破坏。它可能删除文件、窃取信息或占用资源。安装杀毒软件和及时更新系统是有效的防护手段。
A computer virus is malicious code that copies itself and attaches to other programs, spreading and causing harm without the user's knowledge. It may delete files, steal information, or consume resources. Antivirus software and timely updates are effective defenses.

什么是公钥和私钥？

What are public and private keys?

在非对称加密中，公钥可以公开给任何人用来加密或验证签名，私钥必须严格保密用来解密或生成签名。用公钥加密的内容只能用对应私钥解开。这种机制支撑了 HTTPS 和数字签名。
In asymmetric encryption, the public key can be shared with anyone to encrypt or verify signatures, while the private key must be kept secret to decrypt or create signatures. Content encrypted with the public key can only be opened by the matching private key. This mechanism underpins HTTPS and digital signatures.

什么是双因素认证（2FA）？

What is two-factor authentication (2FA)?

双因素认证在密码之外增加第二重验证，例如手机验证码或指纹，证明登录者确实是你。即使密码泄露，攻击者也难以通过第二关。它显著提升了账户安全性。
Two-factor authentication adds a second proof beyond the password, such as a phone code or fingerprint, confirming the login is really you. Even if the password leaks, an attacker still cannot pass the second step. It greatly improves account security.
