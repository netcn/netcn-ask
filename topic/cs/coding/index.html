编程是什么？

What is programming?

编程是教电脑做事情的方法，像给机器人写小纸条。你写一步，它做一步。
Programming is teaching the computer to do things, like writing little notes for a robot. You write one step and it does one step.

什么是开源软件？

What is open-source software?

开源软件把做法公开，谁都能看、能改、能分享。大家一起修，程序就越变越好。
Open-source software publishes its recipe so anyone can see, change, and share it. Everyone helps fix it, and the program gets better.

电脑是怎么画出漂亮图画的？

How does a computer draw pretty pictures?

电脑把颜色一点一点涂在小灯上，拼成整幅画。程序员用代码告诉它哪里该涂红、哪里该涂蓝。
The computer dabs color onto tiny lights to build a whole picture. Programmers use code to say where red goes and where blue goes.

机器人是怎么“思考”的？

How does a robot think?

机器人不会自己想，它照着写好的程序一步步做。程序说往前，它就往前。
A robot does not think on its own; it follows a written program step by step. When the program says go forward, it goes forward.

机器人怎么动起来？

How does a robot move?

机器人身体里藏着小马达，电脑一下令它就转。于是机器人的手和脚就动啦。
A robot hides tiny motors inside, and the computer tells them to spin. Then the robot's hands and feet move.

电子游戏是怎么变出来的？

What is a video game?

电子游戏是程序员用代码搭的小乐园，你在里面跑跳闯关。电脑帮你把画面变得会动。
A video game is a little playground that programmers build with code, where you run and jump. The computer makes the pictures move.
