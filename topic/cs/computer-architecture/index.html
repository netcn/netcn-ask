『内存墙』指的是处理器与内存之间怎样的矛盾？

What contradiction between processor and memory does the 'memory wall' describe?

几十年来 CPU 速度按摩尔定律飞涨，而内存访问延迟下降缓慢，处理器常因等数据而空转，性能被带宽和延迟卡住。Wulf 与 McKee 在 1995 年提出该术语，并推动多级缓存、预取等技术来缓解。
CPU speed rose fast with Moore's law while memory latency improved slowly, so processors often stalled waiting for data and hit a bandwidth/latency ceiling. Wulf and McKee coined the term in 1995 and spurred caches, prefetching, and other mitigations.

GPU 相比 CPU 为什么特别擅长并行运算？

Why are GPUs so much better than CPUs at parallel computation?

GPU 内部有成千上万个轻量核心，专为大量相同操作（如矩阵乘法）的『单指令多数据』并行而设计，适合图形渲染和深度学习。NVIDIA 的 CUDA 编程模型让程序员能把通用计算映射到这些核心。
A GPU packs thousands of lightweight cores tuned for 'single-instruction-multiple-data' parallelism on uniform operations like matrix multiply, ideal for graphics and deep learning. NVIDIA's CUDA model lets programmers map general computing onto those cores.

指令流水线是怎样让 CPU 同时『处理多条指令』的？

How does instruction pipelining let a CPU work on several instructions at once?

流水线把一条指令的执行拆成取指、译码、执行、写回等阶段，不同指令的不同阶段在时间上重叠，像工厂装配线一样提升吞吐。代价是指令相关和分支会带来停顿或冲刷。
Pipelining splits an instruction into stages—fetch, decode, execute, write-back—so different instructions occupy different stages at the same time, raising throughput like a factory line. The cost is stalls or flushes from dependencies and branches.

RISC 与 CISC 两种指令集哲学的根本分歧是什么？

What is the fundamental split between RISC and CISC instruction-set philosophies?

CISC 倾向用较少、较复杂、功能繁多的指令；RISC 则精简为少量简单、定长、单周期为主的指令，把复杂工作交给编译器与流水线。Patterson 等在 1980 年代的系统研究使 RISC 成为 ARM、RISC-V 等现代设计的主流。
CISC favors fewer, more complex, feature-rich instructions; RISC pares down to a small set of simple, mostly fixed-length, fast instructions, leaving complexity to the compiler and pipeline. Patterson's 1980s work made RISC dominant in ARM, RISC-V, and modern designs.

冯·诺依曼体系结构最核心的思想是什么？

What is the central idea of the von Neumann architecture?

它把指令和数据存放在同一可读写的存储器中，由控制器逐条取指、译码、执行，形成『存储程序』范式。这一思想写入 1945 年的《第一份草案》，至今仍是绝大多数计算机的基础。
It stores instructions and data in the same read-write memory and has a control unit fetch, decode, and execute them one by one—the 'stored-program' paradigm. Laid out in the 1945 'First Draft', it still underlies most computers.
