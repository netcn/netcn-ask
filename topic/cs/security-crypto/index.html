什么是数字签名，它如何证明消息未被篡改？

What is a digital signature and how does it prove a message is unaltered?

发送方用私钥对消息哈希值签名，接收方用公钥验证；若消息被改动，哈希对不上，签名即失效，从而证明完整性。
The sender signs a hash of the message with a private key; the receiver verifies with the public key. Any change alters the hash and invalidates the signature, proving integrity.

什么是彩虹表攻击，盐值如何防御它？

What is a rainbow table attack and how does salting defend against it?

彩虹表是预先算好的密码哈希对照表，可快速反查弱密码。给每个密码加随机"盐值"再哈希，能让相同密码产生不同结果，使彩虹表失效。
A rainbow table is a precomputed hash lookup to reverse weak passwords. Adding a random 'salt' before hashing makes identical passwords yield different hashes, defeating the table.

什么是公钥和私钥（非对称加密）？

What are public and private keys (asymmetric encryption)?

非对称加密使用一对密钥：公钥可公开用来加密，私钥保密用来解密，他人用公钥加密的信息只有持有私钥者能解开。
Asymmetric encryption uses a key pair: a public key anyone can use to encrypt, and a private key kept secret to decrypt, so only the private-key holder can read the message.

什么是零知识证明？

What is a zero-knowledge proof?

零知识证明让一方在不透露任何额外信息的情况下，向另一方证明某个陈述为真，常用于隐私保护认证。
A zero-knowledge proof lets one party prove a statement is true to another without revealing anything beyond its truth, used in privacy-preserving authentication.

哈希函数和加密有什么区别？

What is the difference between a hash function and encryption?

哈希把任意数据变成固定长度的摘要且通常不可逆，用于校验完整性；加密可逆，需密钥还原原始数据。
A hash turns data into a fixed-length digest that is usually irreversible, used to verify integrity; encryption is reversible with a key to recover the original data.

What is malware?

什么是勒索软件？

What is ransomware?

勒索软件会加密你的文件并索要赎金才肯解锁，平时应靠备份和及时更新系统来防范。
Ransomware encrypts your files and demands payment to unlock them; defenses include backups and timely system updates.

什么是两步验证？

What is two-step verification?

两步验证在输入密码后还要第二次证明身份，比如短信验证码，即使密码泄露别人也难登录。
Two-step verification asks for a second proof of identity after the password, like a text code, so a leaked password alone is not enough.

A firewall is a guard at the door of a network or computer that checks incoming and outgoing data and blocks suspicious connections.
