什么是费茨定律？

What is Fitts's law?

费茨定律是预测指向任务所需时间的经验公式：目标越远、越小，点中它就越慢。它指导界面把常用按钮做大、放近，从而加快操作、提升效率。
Fitts's law is an empirical formula predicting the time for a pointing task: the farther and smaller the target, the slower to hit it. It guides interfaces to make frequent buttons larger and closer, speeding up interaction.

什么是可用性？

What is usability?

可用性衡量用户能否高效、准确、满意地完成目标，常用易学性、效率、可记忆性和出错率等指标评估。它是界面设计成败的关键，常通过用户测试来发现改进点。
Usability measures how efficiently, accurately, and satisfactorily users achieve goals, assessed by learnability, efficiency, memorability, and error rate. It is central to interface success and is improved through user testing.

什么是示能（Affordance）？

What is an affordance?

示能指物体的设计特征暗示了它该如何被使用，例如门上的把手暗示拉、平板暗示按。在界面里，按钮看起来可点、滑块看起来可拖，都是利用示能降低学习成本。
An affordance is a design feature that hints at how something should be used—a handle suggests pull, a flat plate suggests push. In interfaces, a button looks clickable and a slider looks draggable, using affordances to lower the learning cost.
