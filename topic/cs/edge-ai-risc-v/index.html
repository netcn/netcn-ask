知识蒸馏中「软标签」（soft targets）为什么比硬标签携带更多训练信息？

Why do soft targets carry more training information than hard labels in knowledge distillation?

教师模型输出的软化概率保留了类间相似性（如「2」与「7」的概率分布相近），这些信息作为正则帮助小模型学得更平滑的决策边界。温度参数用于放大暗知识，使蒸馏更有效。
The teacher's softened probabilities preserve class similarities (e.g. a distribution where 2 and 7 are close), acting as a regularizer that helps the small model learn smoother decision boundaries. A temperature parameter amplifies this dark knowledge to make distillation more effective.

训练后 INT8 量化如何把浮点权重映射到整数，并尽量抑制精度损失？

How does post-training INT8 quantization map floating-point weights to integers while suppressing accuracy loss?

量化用缩放因子与零点把 FP32 张量线性映射到 INT8 区间，推理时以整数运算近似浮点并反量化输出。通过校准集统计激活范围或采用逐通道、逐层量化，可在小幅精度下降下获得数倍加速与内存节省。
Quantization uses a scale factor and zero point to map FP32 tensors linearly into the INT8 range, approximating floating-point with integer arithmetic and dequantizing at output. Calibrating activation ranges or using per-channel/per-layer quantization yields several times speedup and memory savings at small accuracy cost.

端侧 AI 推理为什么常以「能效比」（TOPS/W）而非峰值算力衡量芯片？

Why is on-device AI inference often measured by energy efficiency (TOPS/W) rather than peak compute?

电池与散热限制了端侧设备的持续功耗，能否在有限瓦数下完成推理比瞬时峰值更重要。能效比反映每瓦可提供的算力，直接决定续航与可部署性。
Battery and thermal limits cap sustained power on edge devices, so completing inference within a limited wattage matters more than instantaneous peak. Energy efficiency reflects compute per watt and directly determines battery life and deployability.

RISC-V 向量扩展（RVV）如何支持可变长度的 SIMD 计算？

How does the RISC-V vector extension (RVV) support variable-length SIMD computation?

RVV 采用向量长度无关（vector-length agnostic）的设计：硬件实现固定的 VLEN，软件用 vsetvl 指令动态查询并设定实际运行向量长度 VL，使同一份代码能适配不同宽度的硬件。它用掩码与分段加载灵活处理不规则数据，适合端侧并行推理。
RVV uses a vector-length-agnostic design: the hardware fixes VLEN while software uses the vsetvl instruction to query and set the actual runtime vector length VL dynamically, so the same code adapts to different hardware widths. Masks and segmented loads handle irregular data flexibly, suiting on-device parallel inference.

结构化剪枝与非结构化剪枝在部署上有什么差别？

What is the deployment difference between structured and unstructured pruning?

非结构化剪枝随机归零个别权重，压缩比高但需专用稀疏硬件才能提速；结构化剪枝移除整通道或滤波器，能直接在标准硬件上加速。取舍在于稀疏模式是否匹配现有计算库。
Unstructured pruning zeros out individual weights, giving high compression but needing specialized sparse hardware to speed up; structured pruning removes whole channels or filters and accelerates directly on standard hardware. The trade-off is whether the sparsity pattern matches existing compute libraries.

边缘 AI 相比把数据上传云端推理，有哪些主要优势与限制？

What are the main advantages and limitations of edge AI compared with sending data to the cloud for inference?

边缘 AI 在设备端完成推理，能降低延迟、减少带宽占用并保护隐私。限制是端侧算力、内存和功耗有限，往往需要对模型做压缩与硬件加速。
Edge AI performs inference on the device, lowering latency, reducing bandwidth use, and protecting privacy. The limits are constrained on-device compute, memory, and power, which usually require model compression and hardware acceleration.

RISC-V 的「开放指令集架构」对芯片设计意味着什么？

What does an open instruction set architecture like RISC-V mean for chip design?

RISC-V 采用免费开放、模块化的指令集，厂商可自由扩展定制指令而不必授权封闭架构。这降低了芯片设计门槛，便于为 AI、IoT 等场景做领域专用加速。
RISC-V offers a free, open, modular instruction set that vendors can extend with custom instructions without licensing a closed architecture. This lowers the barrier to chip design and eases domain-specific acceleration for AI, IoT, and similar scenarios.
