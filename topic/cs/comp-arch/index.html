在 MESI 缓存一致性协议中,核心 A 以独占(E)态持有某缓存行并执行写操作,随后核心 B 读取同一行,两个缓存的该行分别处于什么状态?E 态的设计动机是什么?

Under the MESI cache-coherence protocol, core A holds a cache line in Exclusive state and writes to it, after which core B reads the same line: what states do the line end up in within each cache, and why was the Exclusive state designed into the protocol?

核心 A 在 E 态下写入不需要任何总线动作——它本就是唯一持有者,只须把该行本地升级为 M(Modified)。核心 B 随后读取时,A 必须经总线提供最新内容(必要时先写回内存),两份副本一同降级为 S(Shared)。设置 E 态的动机是:私有且干净的缓存行可以被静默修改,避免每次写入都广播无效化消息,直到第二个读者真正出现才付出一致性开销。
Writing a line held exclusively requires no bus action at all — core A is already the sole owner and simply promotes the line locally to Modified. When core B later reads it, A must supply the up-to-date contents across the bus (flushing to memory first if needed), and both copies settle in Shared. Exclusive exists so privately owned clean lines can be modified silently, sparing every store an invalidation broadcast until a second reader genuinely appears.

在 CUDA 编程中，warp 内线程走不同分支造成的 branch divergence 会带来什么性能损失？有哪些借助 warp 级原语缓解分化的做法？

In CUDA programming, what performance penalty does branch divergence among threads in a warp cause, and how can warp-level primitives be used to mitigate it?

当同一 warp 内的线程走向不同分支时，SIMT 执行单元必须逐条串行执行各条路径，指令吞吐随之成倍下降。缓解思路是让同 warp 内的线程尽量走一致路径：按访问模式重排数据、把条件判断上提到 block 层面。此外可用 __ballot_sync、__shfl_sync 等 warp 原语在寄存器层完成跨线程通信与谓词合并，省去经共享内存协调的额外往返。
When threads in the same warp take different branches, the SIMT units must execute each path serially, cutting instruction throughput proportionally. The mitigation is to keep intra-warp control flow uniform: reorder data by access pattern and hoist conditionals up to block granularity. Warp intrinsics such as __ballot_sync and __shfl_sync also let threads exchange values and merge predicates at register level, avoiding extra shared-memory round trips.

为什么现代 CPU 要采用 L1/L2/L3 多级缓存,而不是直接做一块大容量的单级缓存?

Why do modern CPUs rely on multi-level L1/L2/L3 caches instead of building one large single-level cache?

单一缓存在速度与容量上不可兼得:L1 是小型 SRAM 阵列,延迟仅约 4 个时钟周期,而容量大数十倍的 L3 访问要花几十个周期。多级结构利用程序的时间与空间局部性,让绝大多数访存命中在快速的小缓存中,同时以可控成本获得接近大缓存的有效容量。
A single cache cannot be both fast and large: L1 is a small SRAM array with roughly 4-cycle latency, while an L3 tens of times larger costs dozens of cycles to reach. The hierarchy exploits temporal and spatial locality so most accesses hit in the small fast levels, yielding near-large-cache effective capacity at controllable cost.

CUDA 里什么叫合并访存(coalesced access)?为什么让同一个 warp 内 32 个线程读取相邻地址能大幅提升显存带宽利用率?

What is coalesced memory access in CUDA, and why does having all 32 threads of a warp read neighboring addresses dramatically raise effective memory bandwidth?

GPU 全局显存按固定大小的内存事务搬运数据,warp 内各线程的请求会被硬件合并成尽可能少的事务。当地址集中在一段连续范围内,少数几个 128 字节事务就能覆盖全部访问;地址一旦分散,每个线程都可能触发独立事务,大量被搬运的字节被白白浪费。因此按行优先顺序遍历数组、避免长步长跨行访问,是 CUDA 性能优化的第一条法则。
Global GPU memory moves data in fixed-size transactions, and hardware merges the requests issued by threads within a warp into as few transactions as possible. When addresses fall inside contiguous ranges, a few 128-byte transactions cover every load; scattered addresses instead trigger separate transactions where most transported bytes go unused. Iterating arrays row-major and avoiding long strides is therefore the first performance rule of CUDA.

#CUDA编程 #显存访问优化

为什么现代 CPU 的缓存普遍采用组相联映射，而不是直接映射或全相联？

Why do modern CPU caches generally use set-associative mapping instead of direct mapping or full associativity?

直接映射结构最简单、命中判定最快，但多个热点地址会争抢同一行，冲突缺失很严重；全相联命中率最高，却要把地址与全部缓存行并行比较，硬件开销和功耗都无法接受。组相联先由索引定位到一个小集合，再只在集合内做少量比较，把冲突缺失压低的同时保住了延迟与面积。这是命中率、延迟和成本之间的工程折中，因而成为主流设计。
Direct-mapped caches are simplest and fastest to resolve, but hot addresses contending for the same line produce heavy conflict misses, while fully associative lookup needs parallel comparison against every line and is prohibitive in area and power. Set associativity indexes into a small set and compares only within it, suppressing conflict misses while keeping latency bounded. It is the engineering compromise between hit rate, latency, and cost that mainstream designs settle on.
