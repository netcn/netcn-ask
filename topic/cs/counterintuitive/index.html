为什么计算机里的“随机数”其实可以预测？

Why are computer 'random numbers' actually predictable?

大多是伪随机：用算法加种子生成，同一种子得到同一串数；真正的随机需要物理噪声等熵源。
Most are pseudo-random from an algorithm and seed, so the same seed yields the same sequence; true randomness needs physical entropy.

为什么任何压缩软件都不能把所有文件压得更小？

Why can’t any compressor shrink every file?

鸽巢原理说明：比原文件小的压缩结果数量少于原文件数量，所以必然存在一些文件无法无损地变得更小。
The pigeonhole principle shows there are fewer smaller outputs than possible inputs, so some files simply cannot be losslessly shrunk.

为什么量子计算机不能“加速”所有问题？

Why can’t quantum computers speed up every problem?

量子算法只在特定结构上有优势，例如Shor分解大数、Grover搜索，对大多数日常任务并没有明显好处。
Quantum algorithms help only on specific structures like Shor’s factoring or Grover’s search; most everyday tasks see no clear gain.

为什么同一段程序在不同电脑上结果可能不同？

Why can the same program give different results on different machines?

浮点舍入、并行执行的竞态、未初始化的内存以及编译器优化差异，都可能让最终结果不完全一致。
Floating-point rounding, parallel race conditions, uninitialized memory, and compiler optimizations can all make results differ slightly.

为什么给电脑加更多CPU核，程序不一定更快？

Why don’t more CPU cores always make a program faster?

阿姆达尔定律指出加速受限于串行部分，且并行有通信和同步开销，纯单线程程序多核完全帮不上忙。
Amdahl’s law says speedup is limited by the serial part, and parallelism adds communication overhead; single-threaded code gains nothing from more cores.

为什么神经网络同一个输入两次回答可能不一样？

Why might a neural network answer the same input differently twice?

推理时若开启随机解码温度、dropout或采样，再加上并行浮点求和顺序不同，输出就可能有非确定性。
With random decoding temperature, dropout, or sampling, plus varying float summation order, outputs can be non-deterministic.

Why is a '100%' battery only an estimate?

电量靠电压变化和电流积分来估算，老化和温度会让误差变大，并不是对化学余量的精确测量。
Charge is estimated from voltage changes and current integration; aging and temperature add error, so it is not an exact chemical measurement.

Many programs assume 60 seconds per minute and 365 days per year; an inserted leap second or day breaks time math and certificate checks.

计算机为什么用二进制（0和1）而不是十进制？

Why do computers use binary (0 and 1) instead of decimal?

电路用高、低电压表示0和1最简单可靠，二进制又和逻辑门天然契合，用十进制电路会更复杂也容易出错。
Circuits represent 0 and 1 with low and high voltage most simply; binary also fits logic gates, while decimal circuits would be complex and error-prone.
