选择公理与佐恩引理是什么？

What are the axiom of choice and Zorn's lemma?

选择公理说可以从任意一族非空集合中各选一个元素；佐恩引理说偏序集中每链有上界则存在极大元。二者在集合论中相互等价，但都独立于常规公理。
The axiom of choice picks one element from each of any family of nonempty sets; Zorn's lemma is equivalent and used to prove existence of maximal objects.

序数（ordinal numbers）是什么？

What are ordinal numbers?

序数不仅表示“有多少”，还表示元素的排列顺序，如 0,1,2,…,ω,ω+1,…。它把“第几个”推广到无穷，是研究良序与超限归纳的工具。
Ordinals encode order, not just size: 0,1,2,…,ω,ω+1,…; they extend 'which position' to infinity for well-orders.

什么是连续统假设？

What is the continuum hypothesis?

连续统假设认为在实数集与自然数集之间不存在“中间大小”的无穷集合。哥德尔与科恩证明它在标准集合论（ZFC）中既不能被证明也不能被否定。
The continuum hypothesis says no set is strictly between naturals and reals in size; it's independent of standard set theory (ZFC).

#集合 #假设

为什么任何一个集合——哪怕本身已是无穷——它的全体子集之集也必定严格更大?这对无穷的层级意味着什么?

Why must the set of all subsets of any given set — even an infinite one — be strictly larger than the set itself, and what does this say about the hierarchy of infinities?

设映射把原集的每个元素x对应到一个子集f(x)。构造新子集D:凡x属于f(x),就不许x进入D;凡x不属于f(x),就把x放进D。于是D与每一个f(x)至少在x这一点上不同,不可能出现在被对应的子集之列——任何配对都注定漏网。这就是康托尔定理:幂集基数严格更大。从自然数出发逐层取幂集,无穷的阶梯无限攀升,永远不存在最大的无穷。
Suppose a mapping assigns to each element x of the original set a subset f(x). Build a new subset D: exclude x whenever x belongs to f(x), and include x whenever it does not. Then D differs from every f(x) at least at the point x, so it cannot appear anywhere among the paired subsets — any pairing is doomed to miss something. This is Cantor's theorem: the power set is always strictly bigger. Taking power sets level after level starting from the naturals, the ladder of infinities climbs forever and there is no largest infinity.

罗素悖论是什么？

What is Russell's paradox?

它考虑“所有不包含自身的集合”是否包含自身：包含则不该包含，不包含则又该包含，自相矛盾。它促使人们建立更严谨的公理集合论（如ZFC）。
Consider the set of all sets not containing themselves; it both must and must not contain itself—a contradiction that motivated axiomatic set theory (ZFC).

什么是交集和并集？

What are intersection and union?

交集是两个集合共有的元素（记作 A∩B），并集是至少属于其中一个集合的所有元素（记作 A∪B）。
Intersection A∩B is elements common to both sets; union A∪B is elements in either.

什么是良序？

What is a well-ordering?

良序是一个全序，其中每个非空子集都有最小元素。自然数按大小是良序的，但整数全体按普通大小不是（没有最小元素）。
A well-order is a total order where every nonempty subset has a least element; naturals are well-ordered, all integers are not.

How does forcing show the continuum hypothesis is undecidable?

什么是大基数？

What are large cardinals?

大基数是一类“极大”无穷基数（如不可达基数、可测基数），其存在性强到无法在标准 ZFC 中证明。它们构成集合论中衡量“强公理”的阶梯。
Large cardinals (inaccessible, measurable, …) are 'very large' infinities whose existence can't be proved in ZFC; they form a hierarchy of strong set-theoretic axioms.

幂集的大小是多少？

What is the size of a power set?

集合 S 的幂集（所有子集的集合）含有 2^|S| 个元素。例如 {a,b} 的幂集有 4 个子集：∅、{a}、{b}、{a,b}。
The power set of S has 2^|S| elements; e.g. {a,b} has 4 subsets.

若有人声称把0到1之间的所有小数排成了一张无穷清单，如何沿对角线造出一个必定不在清单上的数？

If someone claims to have arranged every decimal between 0 and 1 into one infinite list, how can you walk down the diagonal and build a number guaranteed absent from it?

直接构造即可：设清单第n行是一个小数，取出它的第n位数字，改成别的数字（比如0改成1），把这些改动后的数字拼成一个新数。新数与第n行在第n位必然不同，因此绝不在清单上——无论清单如何排列总会漏掉某些数。这说明实数无法与自然数一一对应，是比后者更大的无穷。同一对角线手法后来还支撑了哥德尔不完备定理与图灵停机问题的证明。
Construct it directly. Suppose row n of the list holds some decimal; take its n-th digit, change it to something else (say 0 becomes 1), and assemble the altered digits into a new number. That new number differs from row n at digit n, whatever the list looks like, so no enumeration ever captures every decimal. Real numbers therefore cannot be paired one-to-one with the naturals — a strictly larger infinity. The same diagonal step was later reused in the incompleteness work of Goedel and the halting problem of Turing.

什么是空集？

What is the empty set?

空集是不含任何元素的集合，记作 ∅。它是唯一不含元素的集合，并且是任何集合的子集。
The empty set ∅ has no elements; it's unique and a subset of every set.

什么是子集？

What is a subset?

若集合 A 的所有元素都在集合 B 中，则称 A 是 B 的子集，记作 A ⊆ B。例如 {1,2} 是 {1,2,3} 的子集。
A is a subset of B if every element of A is in B, written A⊆B; e.g. {1,2}⊆{1,2,3}.

一家已经客满的无穷旅馆,凭什么还能同时腾出无穷多个空房间?

How can a fully occupied infinite hotel nevertheless free up infinitely many vacant rooms at once?

「客满」只意味着没有空房,并不代表住不下更多人。让每位客人从n号房搬到n+1号,1号房立刻腾出;要接待无穷多位新客,只需请老客人一律搬进自己的双号房2n,全部单号房便一次性空出。原因是可数无穷集合挪动、配对之后仍是同一个基数:它与自身的一部分一样大——这恰是无穷集合与有限集合最反直觉的分界线。
Full house means no room is empty, not that nobody else fits. Move every guest from room n to room n+1 and room 1 opens at once; to host infinitely many newcomers, send each current guest to their own even-numbered room 2n, vacating every odd-numbered room in one stroke. A countably infinite set keeps the same cardinality after shifting or pairing: it is as large as a part of itself — the sharpest dividing line between infinite and finite sets.
