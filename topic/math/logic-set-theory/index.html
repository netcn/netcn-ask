策梅洛-弗兰克尔集合论（ZF）为现代数学提供了怎样的公理化基础？

What axiomatic foundation for modern mathematics does Zermelo-Fraenkel set theory provide?

ZF集合论用外延、配对、并集、幂集、无穷等少量公理严格界定集合的构造，避免了罗素悖论式的自指矛盾。绝大多数现代数学对象都能在其中被定义，是形式化的共同底层。耶赫与库宁的集合论专著是标准参考。
Zermelo-Fraenkel set theory uses a small set of axioms—extensionality, pairing, union, power set, infinity—to rigorously delimit how sets are built, avoiding self-referential contradictions like Russell's paradox. Nearly all modern mathematical objects can be defined within it, forming a common formal foundation. Jech and Kunen are standard references.

哥德尔不完备定理对形式系统的能力给出了什么根本限制？

What fundamental limit on formal systems do Gödel's incompleteness theorems establish?

哥德尔第一不完备定理证明，任何包含算术且一致的公理化系统，都存在既不能被证明也不能被否证的命题。第二定理进一步说明该系统无法在自身内证明自身的一致性。哥德尔1931年的论文与斯穆里安的书是权威来源。
Gödel's first incompleteness theorem shows that any consistent axiomatic system containing arithmetic has a statement neither provable nor disprovable within it. The second shows the system cannot prove its own consistency from inside. Gödel's 1931 paper and Smullyan's book are authoritative sources.

模型论研究什么？

What does model theory study?

模型论研究形式语言与其解释（模型）之间的关系，关心哪些语句在哪些结构中被满足。它在代数与数论（如Ax-Grothendieck定理）中有惊人应用。
Model theory studies the relation between formal languages and their interpretations (models), i.e. which statements hold in which structures. It has surprising uses in algebra and number theory.

哥德尔完备性定理是什么？

What is Gödel's completeness theorem?

它说一阶逻辑中，一个公式是定理（可证）当且仅当它在所有模型中为真。它把“可证明性”与“普遍真理性”统一起来。
In first-order logic, a formula is provable iff it is true in every model. It unifies provability with universal truth.

力迫法（forcing）是什么？

What is forcing?

力迫法是科恩1963年发明的技术，通过“扩充”集合论宇宙来构造新模型，从而证明连续统假设独立于ZFC。它是现代集合论最有力的工具。
Forcing, invented by Cohen in 1963, extends the set-theoretic universe to build models, proving the continuum hypothesis independent of ZFC. It is the premier tool of modern set theory.

布尔代数是什么？

What is Boolean algebra?

布尔代数是以“与、或、非”运算处理真值的代数系统，只有真与假两个值。它是数字电路与计算机逻辑门设计的数学基础。
Boolean algebra handles truth values with AND, OR, NOT over just true/false. It is the mathematical basis of digital circuits and computer logic gates.

皮亚诺公理是什么？

What are the Peano axioms?

皮亚诺公理用“0 和其后继”公理化了自然数：每个数有唯一后继，0不是任何数的后继，归纳法成立。它给算术提供了严格基础。
The Peano axioms formalize naturals via 0 and a successor: each has a unique successor, 0 is first, and induction holds. They give arithmetic a rigorous foundation.

康托尔对角线论证是什么？

What is Cantor's diagonal argument?

康托尔用构造“对角线”新数的方法证明实数比自然数多，即实数不可数。它是现代集合论与无穷层级的开端。
Cantor proved reals outnumber naturals by constructing a new number differing from each listed one on the diagonal—reals are uncountable. It launched the theory of infinite sizes.
