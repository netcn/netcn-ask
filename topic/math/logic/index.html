柯里-霍华德同构（Curry–Howard）为什么把“数学证明”和“计算机程序”看成同一种东西？

Why does the Curry–Howard isomorphism treat 'a mathematical proof' and 'a computer program' as the same kind of thing?

柯里-霍华德同构指出：逻辑命题对应程序类型，证明对应构造该类型的程序，推理规则对应函数组合。于是“证明一个定理”等价于“写出具有某类型的程序”，类型检查器就是定理证明器；这把直觉主义逻辑与 λ 演算深刻统一，奠定了证明辅助工具（如 Coq）的基础。
The Curry–Howard isomorphism says a logic proposition corresponds to a program type, a proof to a program inhabiting that type, and inference rules to function composition. Thus 'proving a theorem' equals 'writing a program of a given type,' and a type checker is a theorem prover—unifying intuitionistic logic with the λ-calculus and underpinning proof assistants like Coq.

λ 演算是什么？

What is the λ-calculus?

λ 演算是用“匿名函数”和“应用”构成的极简计算模型，仅用变量、抽象与应用三种形式就能表达所有可计算函数。它是函数式编程语言的理论基础。
The λ-calculus is a minimal model of computation built from anonymous functions and application; it can express all computable functions and underlies functional programming.

What is the halting problem?

它问是否存在一个程序能判断任意程序是否会在有限步内停止。图灵证明不存在这样的通用判定程序，说明某些问题本质上不可计算。
The halting problem asks if a program can decide whether any program stops; Turing proved no such universal decider exists—some problems are uncomputable.

P 与 NP 问题是什么？

What is the P vs NP problem?

P 是能在多项式时间内求解的问题类，NP 是能在多项式时间内“验证”解的问题类。P=NP 吗？若相等，许多难题（如调度、密码破解）将迎刃而解，是千禧年难题之一。
P = problems solvable in polynomial time; NP = problems whose solutions are verifiable in polynomial time. Whether P=NP is a Millennium problem with huge consequences.

邱奇-图灵论题是什么？

What is the Church–Turing thesis?

它认为任何“可有效计算”的函数都能被图灵机（或 λ 演算）计算。它并非可证明的定理，而是对“计算”本质被广泛接受的刻画。
The Church–Turing thesis holds that anything effectively computable is computable by a Turing machine (or λ-calculus); it's a widely accepted characterization, not a provable theorem.

什么是哥德尔不完备定理？

What is Gödel's incompleteness theorem?

哥德尔不完备定理表明：任何足够强、包含算术且自洽的形式系统，都存在既不能被证明也不能被否证的命题。它深刻限制了用纯逻辑彻底公理化的梦想。

忙海狸函数是什么？

What is the busy beaver function?

忙海狸函数 Σ(n) 给出 n 状态图灵机在停机前最多能写下的 1 的个数。它增长比任何可计算函数都快，且具体值（如 Σ(5)）极难确定，体现了可计算性的边界。
The busy beaver function Σ(n) is the max ones an n-state Turing machine can write before halting; it grows faster than any computable function and is non-computable.

What is intuitionistic logic?

罗素悖论如何动摇了早期集合论的基础？

How did Russell's paradox shake the foundations of early set theory?

罗素在 1901 年提出：考虑「所有不包含自身的集合」所组成的集合 R——若 R 包含自身则按定义不应包含，若不包含则又应当包含，矛盾。这一悖论击中了朴素集合论中「任意性质定义一个集合」的漏洞，直接推动了公理化集合论（如 ZF 系统）的建立，以避免自指带来的不一致。
Russell (1901) asked about the set R of all sets that do not contain themselves—if R contains itself it shouldn't, and if it doesn't it should, a contradiction. This exposed the flaw in naive set theory's 'any property defines a set' and directly spurred axiomatic set theory (e.g., ZF) to avoid self-referential inconsistency.

What is decidability?

一个问题是可判定的，若存在算法能在有限步内对任一输入给出“是/否”答案。否则不可判定，如停机问题。
A problem is decidable if an algorithm always answers yes/no in finite time; otherwise it's undecidable, like the halting problem.

#逻辑 #类型论

什么是命题逻辑？

What is propositional logic?

命题逻辑把能判真假的陈述当作不可再拆的单位，用「且、或、非、如果…则、当且仅当」拼出复合命题；复合式的真假完全由各部分的真假决定，所以一张真值表就能穷尽所有情形，n 个变元也不过 2 的 n 次方行。它的限度也出在这一步：命题被当成原子，「所有」「存在」这类量词根本表达不出来，「所有人都会死」在这里只是一个 p。要看穿命题内部的主谓结构，就得上升到谓词逻辑。
Propositional logic takes truth-evaluable statements as indivisible units and combines them with "and", "or", "not", "if-then" and "if and only if". The truth of the compound is fixed entirely by the truths of its parts, so one truth table settles every case: n variables give just 2-to-the-n rows. Its limit comes from that same move, since propositions stay atoms: quantifiers like "all" and "some" cannot be expressed at all, and "every man is mortal" is only a single p here. Seeing the subject-predicate structure inside a proposition means ascending to predicate logic.

#逻辑 #命题

1900 年希尔伯特列出的 23 个问题，为什么被称为“数学家的北极星”？

Why are Hilbert's 23 problems, posed in 1900, called a guiding star for mathematicians?

希尔伯特在 1900 年巴黎国际数学家大会上提出 23 个重大问题，像一份“待办清单”，指明了 20 世纪数学的研究方向。一个世纪里它们被逐个攻克：第 7 题（2^√2 的超越性）1934 年解决，第 10 题被证明不可判定，第 1 题（连续统假设）被证明独立于现有公理体系。
At the 1900 International Congress of Mathematicians in Paris, Hilbert listed 23 deep problems as a to-do list that steered twentieth-century research. Over the century they fell one by one: problem 7 (transcendence of 2^√2) was solved in 1934, problem 10 was shown undecidable, and problem 1 (the continuum hypothesis) was proved independent of the standard axioms.

模态逻辑（modal logic）是怎样用“必然”和“可能”扩展普通命题逻辑的？

How does modal logic extend ordinary propositional logic with 'necessity' and 'possibility'?

模态逻辑在“真/假”之外加入算子 □（必然）与 ◇（可能），并引入“可能世界”语义：□P 表示“在所有可达的可能世界 P 都真”，◇P 表示“在某一可能世界 P 真”。它用于哲学、程序验证与知识表示（如“知道”“相信”），是命题逻辑的自然推广。
Modal logic adds operators □ (necessarily) and ◇ (possibly) beyond true/false, with 'possible-world' semantics: □P means P holds in all accessible worlds, ◇P in some world. Used in philosophy, program verification, and knowledge representation (knowing, believing), it naturally extends propositional logic.

什么样的函数在原理上是“可计算”的？

What functions are “computable” in principle?

图灵机把“算法”精确化：任何能用有限条规则描述、能得出确定结果的计算，都可以在一台理想化的图灵机上完成。丘奇-图灵论题断言“可计算”就等于“图灵可计算”。它把计算的概念从具体机器中抽象出来，成为理论计算机科学的基石，也揭示了不可计算问题的存在。
The Turing machine formalizes the notion of algorithm: any computation describable by finitely many rules with a definite outcome can be carried out on an idealized Turing machine. The Church–Turing thesis asserts that “computable” means “Turing-computable”. This abstracts computation away from any physical machine, founding theoretical computer science and exposing the existence of non-computable problems.

为什么维克里（次价）拍卖能鼓励买家如实出价？

Why does the Vickrey (second-price) auction encourage bidders to bid truthfully?

在次价拍卖中，出价最高者成交，但只支付第二高的价格。此时如实报价是最优策略：报高不会改变成交价、却可能让你多付；报低则可能输掉本来能赢的交易。出价只影响能否获胜，不影响支付额，所以说真话是占优策略。维克里因此共享 1996 年诺贝尔经济学奖，这一结果是机制设计的基础。
In a second-price auction the highest bidder wins but pays only the second-highest bid. Truthful bidding is then a dominant strategy: overbidding never changes the price yet risks overpaying, and underbidding risks losing a deal you would have won. The bid affects only whether you win, not what you pay. Vickrey shared the 1996 Nobel Prize in Economics, and this result is foundational to mechanism design.

停机问题为什么是不可判定的？

Why is the halting problem undecidable?

停机问题问：能否写一个程序，判断任意程序对给定输入是否会停下来？图灵 1936 年证明不能。若存在这样的判定程序 H，就可构造程序 P，它在“H 判断 P 会停”时反而死循环，反之则立刻停止，形成矛盾。这说明有些数学问题是任何算法都无法解决的，可计算的边界由此被严格刻画。
The halting problem asks whether one program can decide if any other program will halt on a given input. Turing proved in 1936 that it cannot. If such a decider H existed, one could build a program P that loops forever exactly when H predicts P halts, and stops otherwise—a contradiction. So some mathematical problems are beyond any algorithm, sharply delimiting what is computable.

Why does the liar paradox ('this sentence is false') trouble logicians?

It is the oldest and most typical representative of self-referential paradoxes.

什么是“肯定前件”和“否定后件”这类有效的演绎推理形式？

What are valid deductive forms like 'modus ponens' (affirming the antecedent) and 'modus tollens' (denying the consequent)?

“肯定前件”：若 P→Q 且 P 成立，则 Q 成立；“否定后件”：若 P→Q 且 Q 不成立，则 P 不成立。二者是命题逻辑里最基本的有效推理规则，保证从真前提必然得到真结论，区别于“肯定后件”这种常见的无效推理。
Modus ponens: from P→Q and P, infer Q. Modus tollens: from P→Q and not-Q, infer not-P. These are the fundamental valid inference rules of propositional logic, guaranteeing true conclusions from true premises—unlike the fallacious 'affirming the consequent.'
