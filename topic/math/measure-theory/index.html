测度论中的“零测集”与“几乎处处成立”是什么意思？勒贝格积分理论凭什么可以忽略这类集合？

What do "null set" and "holds almost everywhere" mean in measure theory, and why is Lebesgue integration theory entitled to ignore such sets?

能被总面积任意小的可数区间族覆盖的集合称为零测集：单点与可数集皆属此类，康托尔三分集虽不可数，测度仍为零。“几乎处处”指结论除某个零测集外处处成立，如单调函数几乎处处可微。勒贝格积分对零测集上的取值不敏感：改动这些点上的值不影响积分，仅在零测集上有差异的函数视为相同。这排除了病态例外，使逐点收敛下的积分极限定理得以建立。
A set is null if it can be covered by countably many intervals of arbitrarily small total length. Single points and all countable sets are null, and even the uncountable Cantor ternary set has measure zero. A statement holds almost everywhere when it fails only on some null set — monotone functions, for example, are differentiable almost everywhere. The Lebesgue integral is insensitive to values on null sets: changing a function there alters no integral, and functions differing only on a null set count as identical. This convention discards pathological exceptions and makes the integral limit theorems under pointwise convergence possible.

#测度论 #零测集 #几乎处处 #勒贝格积分

为什么狄利克雷函数（有理数的指示函数）在 [0,1] 上处处不连续、黎曼不可积，但它的勒贝格积分存在且等于 0？

Why is the Dirichlet function (the indicator of the rationals) discontinuous everywhere on [0,1] and not Riemann integrable, yet Lebesgue integrable with value 0?

黎曼积分要求函数在每个小区间上的振幅足够小，但 [0,1] 的任何非空子区间都同时含有有理数与无理数，故上、下积分不相等。勒贝格积分改为按函数值分层：该函数在有理数集上取 1，其余处取 0，而有理数集可数、测度为零，因此积分为 1×0+0×1=0。这体现了勒贝格理论处理极端不连续函数的能力。
Riemann integration requires the oscillation to be small on every subinterval, yet every nonempty subinterval of [0,1] contains both rational and irrational points, so upper and lower sums never agree and the Riemann integral does not exist. Lebesgue integration instead stratifies by values: the function equals 1 on the rationals and 0 elsewhere, and since the rationals are countable they have Lebesgue measure zero, giving 1×0 + 0×1 = 0. This displays the theory's power over extremely discontinuous functions.

#测度论 #勒贝格积分 #黎曼积分 #零测集

勒贝格判据如何只凭不连续点集的大小，就完全判定闭区间上有界函数的黎曼可积性？

How does Lebesgue's criterion fully decide whether a bounded function on a closed interval is Riemann integrable, using only the size of its discontinuity set?

该判据断言：闭区间上的有界函数黎曼可积，当且仅当它的不连续点集是勒贝格零测集。证明思路是用总长度任意小的区间族盖住振幅超过给定阈值的点，从而控制达布上、下和之差。它把可积性问题转化为测度问题：单调函数至多有可数个跳跃间断点，零测因而必可积；而不连续点占满区间的函数必不可积，统一解释了各种病态例子。
Lebesgue's criterion states that a bounded function on [a,b] is Riemann integrable if and only if its discontinuities form a set of Lebesgue measure zero. The proof covers points where oscillation exceeds any threshold by intervals of arbitrarily small total length, controlling the gap between Darboux upper and lower sums. Integrability thus becomes a measure question: monotone functions have at most countably many jumps and always integrate, while everywhere-discontinuous functions cannot.
