曼德博集是什么？

What is the Mandelbrot set?

曼德博集由迭代 z → z² + c 的复数 c 组成，使得从 z=0 出发的轨道不发散。它的边界无限精细、放大后不断出现相似结构，是复动力系统与分形的象征。
The Mandelbrot set is the set of complex c for which iterating z→z²+c from 0 stays bounded; its boundary is infinitely detailed and self-similar—a symbol of fractals.

什么是分形维数（豪斯多夫维数）？

What is fractal (Hausdorff) dimension?

分形维数衡量图形“填充空间”的方式，可以不是整数。科赫雪花周长无限却面积有限，豪斯多夫维数约 1.26；谢尔宾斯基三角垫的维数约 1.58。
Fractal (Hausdorff) dimension measures how a shape fills space and can be non-integer; the Koch snowflake has dimension ≈1.26, the Sierpiński triangle ≈1.58.
