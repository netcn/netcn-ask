停机问题为什么不可解？

Why is the halting problem unsolvable?

假设存在能判断‘任意程序是否停机’的机器 H，就能构造一个利用 H 自相矛盾的程序，使 H 既必须停又必须不停。因此这样的 H 不可能存在。
If a machine H could decide whether any program halts, we could build a program that uses H on itself to contradict—forcing H to halt and not halt. So such an H cannot exist.

图灵机是什么概念？

What is the concept of a Turing machine?

它是一种抽象计算模型：一条无限纸带加一个按规则读写的头，能模拟任何‘算法’。它定义了‘可计算’的边界。
It is an abstract model of computation: an infinite tape plus a head that reads/writes by rules, capable of simulating any 'algorithm'. It defines the boundary of what is computable.

图灵在二战中破了什么密码？怎么做的？

What code did Turing break in WWII, and how?

他帮助破译德军的恩尼格玛（Enigma）密码机。他设计电磁‘炸弹机’（Bombe）利用已知明文和机器结构快速搜索每日密钥，大幅缩短破译时间。
He helped break the German Enigma machine. He designed the electromechanical 'Bombe' that exploited known plaintext and the machine's structure to search daily keys fast, slashing decryption time.
